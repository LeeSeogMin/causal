## 5.1 회귀불연속설계의 기본 원리 📏

### "시험 커트라인" - RDD의 기본 아이디어

회귀불연속설계(RDD)는 Thistlethwaite & Campbell(1960)이 장학금 수혜가 학업 성취에 미치는 영향을 평가하기 위해 처음 제안한 방법이다.

**✏️ 비유로 이해하기: 시험 커트라인**

시험에서 60점이 합격 커트라인이라고 하자. 59점인 학생과 61점인 학생은 실력이 거의 같다. 그런데 61점 학생만 합격하여 장학금을 받았다. 이 두 학생의 이후 성적 차이가 있다면, 그것은 "장학금의 효과"일 가능성이 높다. 이것이 RDD의 핵심 아이디어다.

```
59점 학생 (불합격) vs 61점 학생 (합격) → 이후 성적 차이 = 장학금의 순수 효과
```

비즈니스 맥락에서는 **"전월 구매액 100만 원(기준점) 이상 고객에게 VIP 등급(처치)을 부여할 때, 99만 원 구매자와 101만 원 구매자의 다음 달 구매 패턴 차이"**를 분석하여 VIP 제도의 순수 효과를 추정하는 데 활용된다.

### RDD의 핵심 수식 - 쉽게 읽기

RDD의 핵심은 기준점에서의 "점프"를 측정하는 것이다.

τ = lim(x→c⁺) E[Y|X=x] - lim(x→c⁻) E[Y|X=x]

쉽게 말하면: **"기준점 바로 위 사람들의 평균 결과"에서 "기준점 바로 아래 사람들의 평균 결과"를 빼는 것**이다. 이 차이가 곧 정책 효과다.

### RDD가 작동하는 조건 두 가지

**첫째**, 기준점 근처에서 사람들의 특성이 연속적으로 변해야 한다. 59점 학생과 61점 학생이 능력 면에서 거의 같아야 한다는 뜻이다.

**둘째**, 처치 배정이 기준점에서 불연속적으로 변해야 한다. 60점을 넘으면 확 달라지는 무언가가 있어야 한다.

### RDD의 장점과 한계

**장점:**
- 다른 준실험설계(DID, PSM)보다 가정이 검증 가능하다
- 기준점 근처에서 공변량 균형을 직접 확인할 수 있다
- 윤리적 문제 없이 인과효과를 추정할 수 있다

**한계:**
- 기준점 근처 데이터만 사용하므로 표본이 적다
- 기준점에서 멀리 떨어진 사람들에 대한 효과는 알 수 없다
- 사람들이 점수를 조작할 수 있으면 결과가 왜곡된다

### Sharp RDD vs Fuzzy RDD

**명확 RDD (Sharp RDD)**: 기준점을 넘으면 **100% 처치**, 못 넘으면 **0% 처치**. 가장 이상적인 상황이다. 예: "60점 이상이면 자동으로 장학금 지급"

**퍼지 RDD (Fuzzy RDD)**: 기준점을 넘어도 일부는 처치를 안 받고, 못 넘어도 일부는 처치를 받는 현실적 상황이다. 예: "60점 이상이면 장학금 신청 자격이 주어지지만, 신청 안 하는 사람도 있고, 60점 미만이지만 예외적으로 받는 사람도 있다"

Fuzzy RDD의 추정량은 τₗₐₜₑ = [결과의 점프] / [처치 확률의 점프]로, 도구변수 접근법과 동일하다.

### 💻 실습: Sharp RDD 추정하기

아래 코드는 기준점(cutoff) 근처에서 국소 선형 회귀를 수행하여 처치효과를 추정한다. 배정 변수를 중심화하고 처치-점수 상호작용 항을 포함하여 기준점 좌우의 기울기 차이를 허용한다.

[워크플로우]

1. 기준점 근처 데이터 필터링 (대역폭 h 내)
2. 배정 변수 중심화 (score_centered = score - cutoff)
3. 상호작용 항 생성 (treat_score = treat × score_centered)
4. 국소 선형 회귀: outcome ~ treat + score_centered + treat_score
5. 처치효과 τ 추정 (treat 계수)
6. 대역폭 민감도 분석 (0.5h, 1.0h, 1.5h, 2.0h)
7. 공변량 균형 검정 (연령, 성별, 교육연수 등)
8. 결과 해석 및 타당성 평가

```python
# Sharp RDD 추정 (국소 선형 회귀)
# 데이터 준비: 대역폭 내 관측치 필터링
h = 5.0  # 대역폭
near_cutoff = data[abs(data['score'] - cutoff) <= h].copy()

# 배정 변수 중심화 및 상호작용 항 생성
near_cutoff['score_centered'] = near_cutoff['score'] - cutoff
near_cutoff['treat_score'] = near_cutoff['treat'] * near_cutoff['score_centered']

# 국소 선형 회귀
model = smf.ols('outcome ~ treat + score_centered + treat_score', data=near_cutoff).fit()
tau = model.params['treat']  # 처치효과 추정
```

| --------------- | ------ | -------- | -------- | ------- | ------------ |
| 처치효과 (τ)    | 3.51   | 0.80     | 4.40     | 0.0000  | [1.94, 5.08] |
| 기울기 (왼쪽)   | 0.71   | -        | -        | -       | -            |

| 유효 표본 크기  | 375    | -        | -        | -       | -            |
| 대역폭          | 4.90   | -        | -        | -       | -            |
| R²              | 0.383  | -        | -        | -       | -            |

대역폭 민감도 분석 결과는 다음과 같다. 배정 변수 표준편차(σₓ)의 0.5배를 적용하면 τ̂ = 3.51 (SE = 0.80, n = 375), 1.0배에서 τ̂ = 3.52 (SE = 0.59, n = 691), 1.5배에서 τ̂ = 3.86 (SE = 0.50, n = 861), 2.0배에서 τ̂ = 3.54 (SE = 0.46, n = 956)로 나타났다.

공변량 균형 검정 결과 기준점 근처(±1σ 이내)에서 연령의 불연속은 0.58 (p = 0.618), 성별의 불연속은 0.094 (p = 0.201), 교육연수의 불연속은 0.200 (p = 0.582)으로, 모든 공변량이 통계적으로 유의한 불연속을 보이지 않았다.

🔍 **결과를 쉽게 읽어보면:**

**첫째**, 기준점에서 결과 변수가 **3.51만큼 수직으로 점프**한다(p<0.0001). 이것이 정책의 순수 효과다. 시험 비유로 말하면, "장학금을 받으면 성적이 3.51점 올라간다"는 뜻이다.

**둘째**, 대역폭을 바꿔도 추정값이 3.51~3.86 범위에서 안정적이다. 이는 **"돋보기를 가까이 대든 멀리서 보든 비슷한 결과가 보인다"**는 뜻으로, 결과의 신뢰성이 높다는 증거다.

**셋째**, 기준점 근처에서 연령, 성별, 교육연수 등의 차이가 없다(모든 p > 0.2). 이는 **"59점 학생과 61점 학생이 점수 빼고는 비슷한 사람들"**이라는 RDD의 핵심 가정이 성립함을 보여준다.

**넷째**, R² = 0.383이 낮게 보일 수 있지만, RDD에서는 정상이다. 목적이 "결과 변수 전체를 설명"이 아니라 **"기준점에서의 점프를 정확히 측정"**하는 것이기 때문이다.

## 5.2 비모수적 추정과 대역폭 선택 🔬

### "돋보기 배율 조절" - 대역폭 선택의 핵심

앞 절에서 국소 선형 회귀를 사용한 Sharp RDD를 살펴보았다. 그런데 중요한 질문이 남아있다: **기준점 근처를 "얼마나 가까이 볼 것인가"?** 이것이 바로 대역폭(bandwidth) 선택 문제다.

**🔎 비유로 이해하기: 돋보기 배율**

돋보기로 기준점 근처를 관찰한다고 생각하자.

- **배율이 너무 높으면** (대역폭이 좁으면): 아주 가까이 보니 정확하지만, 보이는 데이터가 너무 적어서 "이게 진짜인지 우연인지" 구분이 어렵다 → 분산이 크다
- **배율이 너무 낮으면** (대역폭이 넓으면): 데이터는 많지만, 기준점에서 멀리 떨어진 사람들까지 포함해서 "정확한 점프"를 측정하기 어렵다 → 편향이 크다

최적 대역폭은 이 **편향-분산 트레이드오프**의 균형점이다. Imbens & Kalyanaraman(2012)은 MSE(평균제곱오차)를 최소화하는 최적 대역폭을 자동으로 선택하는 알고리즘을 제안했다.

### IK 알고리즘의 원리 - 간단하게

IK 대역폭 선택은 세 단계로 진행된다:

1. **잔차 분산 추정**: 3차 다항 회귀로 전체 데이터의 "노이즈 수준(σ²)"을 파악
2. **곡률 추정**: 기준점 좌우에서 2차 회귀로 "데이터가 얼마나 구불구불한지(m₂)" 파악
3. **최적 대역폭 계산**: hₒₚₜ = Cₖ [σ² / (N·m₂²)]^(1/5)

직관적으로: 노이즈가 크면(σ² 큼) → 대역폭을 넓혀 더 많은 데이터 사용. 데이터가 구불구불하면(m₂ 큼) → 대역폭을 좁혀 기준점 가까이만 사용.

### 💻 실습: 최적 대역폭 선택

```python
# Imbens-Kalyanaraman 최적 대역폭 선택 (핵심 로직)
# 1단계: 3차 다항으로 잔차 분산 σ² 추정
# x_poly3 = np.vander(x, 4)[:, :3]  # 3차 다항 행렬 생성
model_global = sm.OLS(y, sm.add_constant(x_poly3)).fit()
sigma_sq = np.var(model_global.resid)

# 2단계: 좌우에서 2차 회귀로 m₂ 추정
# x_left_poly2 = np.vander(x_left, 3)[:, :2]  # 2차 다항 행렬
model_left = sm.OLS(y_left, sm.add_constant(x_left_poly2)).fit()
m2_left = 2 * model_left.params[2]  # β₂ = f''(c)/2 이므로 m₂ = 2|β₂|

# 3단계: MSE 최소화 대역폭
# m22 = m₂²로 계산 (오타 주의)

h_opt = C_K * ((sigma_sq / (N * m22)) ** 0.2)
```

🔍 **결과를 쉽게 읽어보면:**

**첫째**, IK 알고리즘이 선택한 최적 대역폭은 6.17이다. 이는 **"기준점 좌우 6.17점 범위의 학생들만 비교하라"**는 뜻이다. 이 범위에서 550명의 유효 표본이 확보된다.

**둘째**, 어떤 대역폭을 사용하든 처치효과 추정값이 2.58~2.76 범위에서 안정적이다. 이는 **"돋보기 배율을 바꿔도 비슷한 결과가 보인다"**는 뜻으로, 대역폭 선택이 결론에 큰 영향을 미치지 않는다.

**셋째**, MSE 관점에서 Rule-of-thumb(1.38)이 가장 좋지만, IK(1.44)와 거의 같다. 실무에서는 여러 방법을 병행하여 결과의 안정성을 확인하는 것이 중요하다.

**넷째**, 커널 함수(삼각, 엡스타인, 균등)에 따라 추정값이 2.43~2.76으로 약 14% 변동한다. 삼각 커널은 기준점에 가까운 데이터에 더 큰 가중치를 주므로 가장 "국소적인" 추정을 제공한다.

Lee & Lemieux(2010)는 RDD 분석에서 여러 대역폭에서의 추정 결과를 시각적으로 제시하고, 산점도와 국소 다항 곡선을 함께 보여줄 것을 권고하였다.

## 5.3 RDD 타당성 검증: 4가지 핵심 검정 🔍

### "시험 부정행위 탐지" - 왜 검증이 필요한가?

RDD가 신뢰할 수 있으려면 **"기준점 근처에서 아무도 점수를 조작하지 않았다"**는 것을 확인해야 한다. 시험 비유로 말하면, "커트라인 근처에서 부정행위가 없었는지" 검사하는 과정이다.

![조건부 평균 처치효과(CATE) 이질성 분석과 정책 대상화 전략](../diagrams/5-2.png)

### 4가지 핵심 검정

**① McCrary 밀도 검정** 🔍
"기준점 직전에 사람이 비정상적으로 몰려있지 않은가?" 만약 60점 커트라인 바로 아래(58~59점)에 학생이 비정상적으로 많다면, 점수를 조작한 증거다.

**② 공변량 균형 검정** ⚖️
"기준점 앞뒤 사람들이 점수 빼고 비슷한가?" 연령, 성별, 교육연수 등이 기준점에서 불연속을 보이면 안 된다.

**③ 플라시보 기준점 검정** 💊
"가짜 기준점에서도 효과가 나타나는가?" 진짜 기준점(60점)이 아닌 다른 지점(55점, 65점)에서 RDD를 해봤을 때 효과가 없어야 한다. 만약 있다면 우리가 본 효과가 진짜가 아닐 수 있다.

**④ 도넛홀 검정** 🍩
"기준점 바로 근처 관측치를 빼도 결과가 비슷한가?" 기준점 ±0.5 범위를 제거해도 추정값이 안정적이면, 특정 관측치에 과도하게 의존하지 않는다는 증거다.

### 💻 실습: 4가지 타당성 검정

```python
# McCrary 밀도 검정 (실습 목적 간소화 버전)
# 주의: 실무에서는 rddensity 패키지 사용 권장
# 좌우 커널 밀도 추정
kde_left = gaussian_kde(x[x < cutoff])
kde_right = gaussian_kde(x[x >= cutoff])

# 기준점에서 로그 밀도 차이 및 t-통계량
log_diff = np.log(kde_right(cutoff)) - np.log(kde_left(cutoff))
# se 계산은 부트스트랩으로 수행 (실습 목적 생략)
# se = bootstrap_se(kde_left, kde_right, n_bootstrap=1000)
t_stat = log_diff / se  # se=0 방지 필요
p_value = 2 * (1 - norm.cdf(abs(t_stat)))
```

## 5.4 퍼지 회귀불연속(Fuzzy RDD)과 도구변수 접근 🎟️

### "추천장은 받았지만..." - 불완전 순응의 현실

현실에서는 기준점을 넘어도 **모든 사람이 처치를 받지는 않는다**. 예를 들어 청년 취업 지원 프로그램에서 만 34세 이하면 자격이 주어지지만, 자격이 있어도 신청 안 하는 사람이 있고, 34세 초과여도 예외적으로 참여하는 사람이 있다.

**🎟️ 비유로 이해하기: 콘서트 추천장**

콘서트 무료 입장 추천장을 받았다고 하자. 추천장을 받은 사람(기준 충족) 중에도 안 가는 사람이 있고, 추천장 없이도 돈 내고 가는 사람이 있다. 이런 상황에서 "콘서트 관람이 음악 취향에 미치는 효과"를 추정하려면?

Fuzzy RDD는 **"추천장 여부"를 도구변수로 사용**하여, **"실제로 간 사람 중 추천장 때문에 간 사람들(순응자)"**에 대한 효과를 추정한다.

### Fuzzy RDD의 작동 원리

Fuzzy RDD는 도구변수(IV) 프레임워크로 해석한다:

- **도구변수 (Z)**: 기준점 통과 여부 (추천장 받았는지)
- **내생변수 (D)**: 실제 처치 수혜 여부 (실제로 갔는지)
- **결과 (Y)**: 관심 있는 결과 변수

τₗₐₜₑ = [결과의 점프] / [처치 확률의 점프]

이 추정량이 유효하려면 세 가지 가정이 필요하다:
- **관련성**: 기준점에서 처치 확률이 확 달라져야 한다 (추천장이 실제로 가는 데 영향을 미쳐야)
- **배제제약**: 추천장 자체는 결과에 영향 없고, 오직 "실제로 감"을 통해서만 영향
- **단조성**: 추천장 때문에 오히려 안 가는 사람(반항자)은 없어야

### 💻 실습: Fuzzy RDD 2SLS 추정

아래 코드는 청년 취업 지원 프로그램의 Fuzzy RDD를 국소 2SLS로 추정한다. 1단계에서 처치 수혜율의 불연속을 확인하고, 2단계에서 LATE를 추정한다.

[워크플로우]

1. 1단계 회귀: treatment ~ above_cutoff + score_centered + above_score
2. 1단계 F-통계량 계산 (F > 10 기준 평가)
3. 처치 예측값 treatment_hat 생성
4. 2단계 회귀: outcome ~ treatment_hat + score_centered + above_score
5. τₗₐₜₑ 추정 (treatment_hat 계수)
6. 강건 표준오차 계산 (linearmodels.IV2SLS 권장)
7. 축약형 효과 / 1단계 효과 비율 확인
8. Sharp RDD와 비교 (순응률 고려)

```python
# Fuzzy RDD 2SLS 추정 (핵심 단계)
# ⚠️ 주의: 이 수동 2SLS 방식은 실습 목적의 예제입니다.
# 실무/정확한 추정 시 linearmodels.IV2SLS 또는 statsmodels IV 패키지 사용을 권장합니다.

# 1단계: D를 Z에 회귀
first_stage = smf.ols('treatment ~ above_cutoff + score_centered + above_score',
                      data=near_cutoff).fit()

# 2단계: Y를 D̂에 회귀
treatment_hat = first_stage.fittedvalues
second_stage = smf.ols('outcome ~ treatment_hat + score_centered + above_score',
                       data=near_cutoff).fit()

# 권장: linearmodels를 사용한 정확한 표준오차 계산
```

## 5.5 기계학습과 RDD의 통합: 이중 기계학습(DML) 🤖

### "AI 보정 안경" - 왜 기계학습이 필요한가?

지금까지의 RDD는 국소 선형 회귀에 기반한다. 하지만 현실에서는 세 가지 문제가 있다:

1. **고차원 공변량**: 소득, 연령, 지역, 직업 등 수십 개의 변수가 결과에 영향
2. **비선형 관계**: 기준점 근처에서도 복잡한 패턴 존재
3. **이질적 효과**: 사람마다 정책 효과가 다름

**🤖 비유로 이해하기: AI 보정 안경**

기존 RDD가 "맨눈으로 기준점 점프를 관찰"하는 것이라면, DML-RDD는 **"AI 보정 안경을 쓰고 관찰"**하는 것이다. 이 안경은 나이, 소득, 교육 등 방해 요인의 영향을 자동으로 제거해주므로, **진짜 정책 효과만 깨끗하게 볼 수 있다.**

Noack et al.(2024)이 제안한 RDFlex는 이 아이디어를 구체화한 것으로, DML 프레임워크를 RDD에 적용하여 고차원 공변량을 유연하게 조정한다.

### DML-RDD의 작동 원리 - 3단계

**1단계**: 결과 변수 Y를 공변량으로 예측하는 모델 학습 (Random Forest 등)
**2단계**: 처치 여부 D를 공변량으로 예측하는 모델 학습
**3단계**: 각각의 "잔차"(예측에서 벗어난 부분)를 사용하여 처치효과 추정

핵심은 K-fold 교차 적합(cross-fitting)이다. 데이터를 5등분하여, 학습에 사용하지 않은 데이터에서 예측하여 과적합을 방지한다.

### 💻 실습: DML-RDD 추정

```python
# DML-RDD 핵심 알고리즘 (5-fold 교차 적합)
from sklearn.model_selection import KFold
from sklearn.ensemble import RandomForestRegressor

# 대역폭 내 데이터 필터링
near_data = data[abs(data['score'] - cutoff) <= h]
kf = KFold(n_splits=5, shuffle=True, random_state=42)
theta_list = []

for train_idx, test_idx in kf.split(near_data):
    train, test = near_data.iloc[train_idx], near_data.iloc[test_idx]

    # 1단계: 대조군에서 μ₀(X) 학습
    control_train = train[train['treat'] == 0]
    rf_outcome = RandomForestRegressor().fit(control_train[covariates], control_train['outcome'])

    # 2단계: π(X) 학습
    rf_treat = RandomForestRegressor().fit(train[covariates], train['treat'])

    # 3단계: 직교화된 잔차
    y_res = test['outcome'] - rf_outcome.predict(test[covariates])
    d_res = test['treat'] - rf_treat.predict(test[covariates])

    # 4단계: 커널 가중 theta 추정
    K_h = triangular_kernel((test['score'] - cutoff) / h)

    theta = np.sum(K_h * y_res * d_res) / np.sum(K_h * d_res**2)
    theta_list.append(theta)

theta_dml = np.mean(theta_list)
se_dml = np.std(theta_list) / np.sqrt(len(theta_list))
```

### DML-RDD를 언제 써야 할까? - 실용적 가이드

DML-RDD가 항상 좋은 것은 아니다. 다음 경우에 특히 유용하다:

- 기준점 근처에서 **공변량 불균형**이 발견될 때
- 공변량과 결과의 관계가 **비선형적**일 때
- 공변량이 **수십 개 이상**으로 많을 때

## 5.6 이질적 처치효과 추정: CATE와 BART 💊

### "맞춤 처방" - 사람마다 다른 정책 효과

지금까지의 RDD는 **평균** 처치효과 하나만 추정했다. 하지만 현실에서는 사람마다 정책 효과가 다르다. 같은 약이라도 사람마다 효과가 다르듯이, 같은 정책이라도 **사전 성과, 나이, 소득에 따라 효과가 크게 다를 수 있다.**

**💊 비유로 이해하기: 맞춤 처방**

의사가 모든 환자에게 같은 약을 주는 대신, 환자의 체질, 나이, 기저질환에 따라 **맞춤 처방**을 한다면 효과가 더 좋을 것이다. CATE(조건부 평균처치효과) 추정이 바로 이것이다. τ(x) = E[Y₁ - Y₀|X=x]로, **"이 특성을 가진 사람에게 정책 효과가 얼마인지"**를 개인별로 추정한다.

### CATE 추정 방법들

**T-학습기 (T-learner)**: 가장 직관적인 방법. 처치군과 대조군에 각각 별도 모델을 학습한 뒤, 예측값의 차이로 CATE를 추정한다.

**BART (Bayesian Additive Regression Trees)**: Chipman et al.(2010)이 제안한 비모수적 베이지안 방법. 여러 개의 약한 결정 트리를 합쳐서 복잡한 비선형 관계를 포착하면서도, 베이지안 정규화로 과적합을 방지한다.

**인과 포레스트 (Causal Forest)**: Wager & Athey(2018)이 제안한 방법으로, 랜덤 포레스트를 인과추론에 특화시킨 것이다.

### 💻 실습: T-학습기로 CATE 추정

```python
# T-학습기(T-learner)로 CATE 추정 (핵심 로직)
# 처치군과 대조군 별도 학습
model_1 = GradientBoostingRegressor().fit(treated[X], treated['Y'])
model_0 = GradientBoostingRegressor().fit(control[X], control['Y'])

# CATE 예측: τ(x) = E[Y|X, D=1] - E[Y|X, D=0]

cate = model_1.predict(X_new) - model_0.predict(X_new)
```

## 5.7 지리적 경계 회귀불연속설계(Geographic RDD) 🗺️

### "행정구역 경계선" - 지도 위의 RDD

전통적인 RDD가 시험 점수나 나이 같은 1차원 배정 변수를 사용하는 반면, **지리적 RDD(Geographic RDD)**는 행정 구역 경계선을 불연속점으로 활용한다.

**🗺️ 비유로 이해하기: 강남/강북**

서울에서 한강을 경계로 강남에만 특정 정책이 시행되었다고 하자. 한강 바로 남쪽 동네와 바로 북쪽 동네는 지리적으로 가까워 주민 특성이 비슷하지만, 정책은 확 달라진다. 이 차이를 이용하면 정책 효과를 추정할 수 있다. Keele & Titiunik(2015)이 이 방법론을 체계화했다.

### 지리적 RDD의 핵심 가정

**공간적 연속성 가정**: Tobler의 지리학 제1법칙 — "모든 것은 다른 것과 관련되어 있지만, **가까운 것이 더 관련되어 있다**" — 을 기반으로 한다. 경계선에서 가까울수록 양쪽 주민의 특성이 비슷하다는 가정이다.

### 주의사항

- 경계선이 산맥이나 강을 따라 설정된 경우, 양쪽 지역의 특성이 자연적으로 다를 수 있어 가정 위반 가능
- 경도(longitude) 등 공간적 추세를 통제해야 정확한 추정 가능
- 사람들이 혜택을 찾아 경계 안쪽으로 이주하는 "주거지 선택(sorting)" 문제 주의

![지리적 경계를 활용한 RDD(Geographic RDD)의 개념과 공간적 분석](../diagrams/5-3.png)

### 💻 실습: 지리적 RDD 분석

아래 코드는 가상 도시 데이터에서 행정 구역 경계선(위도 5.0)을 기준으로 지리적 RDD를 수행한다. 경도를 통제하여 공간적 추세를 보정한다.

```python
# 지리적 회귀불연속(Geographic RDD) 분석 (1D: Distance to Border)
# 경계선 근처 데이터 필터링 (Bandwidth = 2.0)
bandwidth = 2.0
df_near = data[abs(data['dist_lat']) <= bandwidth].copy()

# 국소 선형 회귀 (Local Linear Regression)
# 모형: Y ~ T + dist + T*dist + longitude (경도 통제)
# 지리적 회귀불연속에서는 경계선을 따라 이동할 때의 변동(경도)을 통제하는 것이 중요함
model_grdd = smf.ols('outcome ~ treat + dist_lat + treat:dist_lat + longitude', data=df_near).fit()

print(model_grdd.summary())
```

## 5.8 한국 정책 평가 및 비즈니스 적용 과제 🇰🇷

### 한국에서 RDD가 유용한 이유

한국의 정책 환경은 RDD 적용에 유리한 점이 많다:

- **명확한 수치 기준**: 소득, 나이, 점수 등으로 정책 자격을 결정하는 제도가 풍부 (기초연금 65세, 청년 정책 34세 등)
- **행정 데이터 디지털화**: 배정 변수와 결과 변수를 정밀하게 측정 가능
- **윤리적 대안**: 무작위 실험이 어려운 상황에서 인과효과 추정 가능
- **지리적 경계 활용**: 투기과열지구, 특별계획구역 등의 경계선 활용 가능

### 한국에서 RDD의 한계

- 정책 설계 단계에서 평가 가능성을 고려하지 않아, 기준점이 불명확하거나 조작 가능한 경우가 많다
- 기준점 근처 표본이 적어 통계적 검정력이 부족한 경우가 있다
- 방법론 전문 인력이 부족하여 대역폭 선택, 타당성 검정 등 핵심 단계가 생략되는 경우가 있다

### 비즈니스 데이터 사이언스 활용

RDD는 공공 정책뿐만 아니라 기업의 전략적 기준선 설정에도 활용된다:

- **핀테크**: 신용 점수 커트오프를 기준으로 대출 한도 상향 효과 분석
- **이커머스**: 무료 배송 기준 금액(예: 3만 원) 전후의 장바구니 크기 변화 분석
- **교육**: 수능 점수/내신 등급 기준 장학금 효과 평가

### 향후 발전 방향

한국에서 RDD의 효과적 활용을 위해서는 정책 설계 단계에서 평가 가능성을 고려하고, 행정 데이터의 연구 목적 활용을 확대하며, RDD 방법론 교육을 확충해야 한다. 기계학습과의 통합(DML-RDD, CATE 분석)은 한국 정책 평가의 품질을 한 단계 높일 수 있을 것이다.

OECD 국가 중 미국(What Works Clearinghouse), 영국(Magenta Book) 등은 RDD를 정책 평가의 표준 방법론으로 인정하고 있다. 한국도 이러한 체계를 구축할 필요가 있다.

## 📝 핵심 정리

| 방법 | 핵심 아이디어 | 비유 | 언제 사용? | 한계 |
|------|--------------|------|-----------|------|
| **Sharp RDD** | 기준점에서 100% 처치 변화 | 시험 커트라인 (60점 이상 합격) | 기준점이 명확하고 완벽히 지켜질 때 | 기준점 근처만 분석 가능 |
| **대역폭 선택 (IK)** | 편향-분산 균형 최적화 | 돋보기 배율 조절 | 항상 (최적 범위 자동 선택) | 유한 표본에서 불안정 가능 |
| **타당성 검증** | 4가지 핵심 검정 | 시험 부정행위 탐지 | 항상 (결과 신뢰성 확보) | 가정을 완벽히 증명할 수 없음 |
| **Fuzzy RDD** | 불완전 순응 하에서 LATE 추정 | 추천장 (받아도 안 가는 사람) | 기준점이 처치를 100% 결정하지 않을 때 | 표준오차 증가, 순응자만 분석 |
| **DML-RDD** | ML로 교란 변수 제거 | AI 보정 안경 | 고차원 공변량, 비선형 관계 | 블랙박스 모델, 표본 많이 필요 |
| **CATE/BART** | 개인별 맞춤 효과 추정 | 맞춤 처방 | 이질적 효과 분석, 정책 targeting | 표본 제한, 과적합 위험 |
| **Geographic RDD** | 행정 경계선 활용 | 강남/강북 경계 | 지리적 경계에서 정책 변화 | 주거지 선택, 공간 자기상관 |
