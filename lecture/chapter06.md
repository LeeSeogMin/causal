## 6.1 내생성: OLS 추정치가 어긋나는 조건

### 왜 필요한가

헬스장 회원권을 끊은 사람(D=1)과 안 끊은 사람(D=0)의 1년 뒤 체중 변화(Y)를 비교했더니, 회원권을 끊은 쪽이 평균 4kg 더 빠졌다고 하자. 여기서 "회원권의 효과가 4kg"이라고 말하면 틀린다. 회원권을 끊는 사람은 원래 건강에 관심이 많은 사람이고, 그 관심(U)은 식단 조절과 수면과 계단 이용에도 영향을 주므로, 4kg 안에는 회원권 효과와 원래 성향의 효과가 섞여 있다.

같은 구조가 정책과 비즈니스 곳곳에 있다.

- 학원 수강(D) → 성적(Y), 숨은 원인 U = 학습 동기
- 직업훈련 참여(D) → 취업률(Y), 숨은 원인 U = 구직 의지
- 배달앱 쿠폰 사용(D) → 월 주문액(Y), 숨은 원인 U = 원래 배달을 자주 시키는 성향
- 대학 졸업(D) → 임금(Y), 숨은 원인 U = 능력·가정 배경

이 상황을 **내생성**(endogeneity)이라고 부른다. 처치 D가 오차항에 들어간 숨은 원인 U와 함께 움직이는 상태다.

![그림 6-1. 내생성의 구조](../diagrams/6-1.png)

빨간 U에서 화살표가 **두 개** 나가는 것이 문제의 전부다. D와 Y가 동시에 U의 영향을 받으므로, D와 Y가 같이 움직여도 그것이 D 때문인지 U 때문인지 구분되지 않는다.

내생성이 생기는 경로는 세 가지다.

**표 6.1** 내생성이 생기는 세 경로

| 경로 | 설명 | 일상 예 |
|------|------|---------|
| 생략변수 편향 | 관측 못 한 원인이 D와 Y 둘 다 움직임 | 건강 관심도가 헬스장 등록과 체중을 동시에 좌우 |
| 측정오차 | 실제 처치가 아니라 잘못 측정된 값을 씀 | 설문에서 "주당 운동시간"을 부풀려 답함 |
| 역인과·동시성 | Y가 D를 되밀어 결정함 | 손님이 몰리는 식당이 가격을 올림 |

세 경로 모두 결과는 같다. D의 변동에 Y와 따로 연결된 부분이 섞여 들어가므로, D의 계수를 그대로 인과효과로 읽으면 어긋난다.

### 무엇을 계산하는가

편향의 크기는 곱셈 하나로 나온다.

```
OLS 편향 = (U가 Y를 바꾸는 크기) × (D가 U와 얼마나 붙어 있는지)
```

앞의 항은 `Y ~ D + X1 + X2 + U` 회귀의 U 계수이고, 뒤의 항은 `U ~ D + X1 + X2` 회귀의 D 계수다. 실습 데이터 `practice/chapter06/data/6-1-iv-data.csv`는 참값(진짜 인과효과)이 **3.42**로 설정되어 있고 관측 못 하는 U까지 검증용으로 들어 있으므로, 이 곱셈을 직접 확인할 수 있다.

### 코드로 해 보기

```python
import pandas as pd, statsmodels.formula.api as smf
df = pd.read_csv('practice/chapter06/data/6-1-iv-data.csv')

print(smf.ols('Y ~ D + X1 + X2 + U', data=df).fit().params['U'])   # -1.946
print(smf.ols('U ~ D + X1 + X2', data=df).fit().params['D'])       #  0.625
print(smf.ols('Y ~ D + X1 + X2', data=df).fit().params['D'])       #  2.171
```

_전체 코드는 practice/chapter06/code/6-1-traditional-2sls.py 참고_

### 결과를 읽는 법

**표 6.2** 예측 편향과 실제 편향의 대조

| 항목 | 값 | 재는 방법 |
|------|-----|-----------|
| U가 Y를 바꾸는 크기 | **-1.946** | `Y ~ D + X1 + X2 + U` 회귀에서 U 계수 |
| D가 U와 붙어 있는 정도 | **0.625** | `U ~ D + X1 + X2` 회귀에서 D 계수 |
| 예측 편향 | -1.946 × 0.625 = **-1.216** | 위 두 값의 곱 |
| 실제 편향 | 2.171 - 3.42 = **-1.249** | OLS 추정값 - 참값 |

예측 편향 -1.216과 실제 편향 -1.249가 거의 일치한다. 편향은 우연이 아니라 계산되는 값이다.

방향 판정은 부호의 곱으로 한다. 이 데이터에서 `Corr(D, U) = 0.527`로 양수인데도 편향은 음수인데, U의 계수가 음수(-1.946)이기 때문이다. **"내생성이 있으면 과대추정된다"는 말은 틀렸다.** 두 값의 부호가 같으면 위로, 다르면 아래로 어긋난다고 판정한다.

### 발견하기 어려운 이유

OLS는 오류 메시지를 내지 않는다. 표준오차 0.065, p값 0.000, 결정계수까지 전부 정상으로 나오는데 값만 36.5% 어긋나 있다.

**비유: 눈금이 어긋난 체중계.** 체중계 눈금이 3kg 낮게 나오도록 어긋나 있다고 하자. 이 체중계는 고장 신호를 주지 않고, 매번 소수점 첫째 자리까지 또렷하게 찍히며, 같은 사람을 열 번 재도 값이 거의 같다.

**표 6.3** 어긋난 체중계와 내생성 있는 OLS의 대응

| 어긋난 체중계 | 내생성 있는 OLS |
|---------------|-----------------|
| 소수점까지 또렷한 눈금 | 작은 표준오차 0.065 |
| 열 번 재도 값이 같음 | 좁은 신뢰구간 [2.043, 2.298] |
| 고장 표시등이 없음 | 오류 메시지도 경고도 없음 |
| 항상 3kg 낮게 나옴 | 항상 1.249 낮게 나옴 |
| 저울에 표준 분동을 올려야 발견 | 도구변수를 써야 발견 |

이 비유는 여기까지만 맞다. 체중계는 분동으로 오차를 직접 재서 눈금을 되돌릴 수 있지만, 실제 연구에서는 참값을 모르므로 편향의 크기를 직접 잴 수 없다. 그래서 값을 고치는 대신 애초에 편향이 섞이지 않는 변동만 골라 쓰는 방법이 필요하다.

## 6.2 도구변수: 처치의 일부만 골라 쓰는 방법

### 왜 필요한가

D 전체는 믿을 수 없지만, D를 통째로 버릴 필요는 없다. **D 안에서 U와 무관하게 움직인 부분만** 골라내면 그 부분으로 효과를 계산할 수 있고, 그 부분을 골라내는 장치가 도구변수 Z다.

헬스장 예로 돌아가자. 사람마다 헬스장 등록 여부는 건강 관심도(U)로 정해지지만, 집에서 헬스장까지의 거리도 등록에 영향을 준다. 거리는 그 사람의 건강 관심도와 상관없이 정해진 조건이므로, "거리가 가까워서 등록한 사람들"의 등록 여부는 U와 무관한 변동이다.

![그림 6-2. 유효한 도구변수의 3조건](../diagrams/6-2.png)

점선 화살표가 **없어야 한다**는 것이 IV의 가장 어려운 조건이다.

### 무엇을 계산하는가

**표 6.4** 유효한 도구변수의 3조건

| 조건 | 뜻 | 데이터로 확인 | 헬스장 예 |
|------|-----|--------------|----------|
| 관련성(Relevance) | Z가 D를 실제로 움직인다 | **가능** (1단계 회귀·F통계량) | 거리가 가까우면 등록률이 높다 |
| 배제제약(Exclusion) | Z는 D를 통해서만 Y에 영향 | **불가능** (논리로 설득) | 거리 자체가 체중을 바꾸지는 않는다 |
| 외생성(Exogeneity) | Z가 U와 무관하다 | **부분적** | 거리가 건강 관심도와 무관해야 한다 |

세 조건 중 하나만 데이터로 검증되고 나머지 둘은 제도·상식·맥락으로 설득해야 하므로, IV 논문은 도구변수 설명에만 여러 쪽을 쓴다. 각 조건이 깨지는 상황은 다음과 같다.

- **관련성이 깨지는 경우**: 거리와 등록률의 관계가 거의 없다면 골라낼 변동 자체가 없어서, 추정치의 표준오차가 커지고 값이 크게 어긋난다. 판정 기준은 6.4에서 다룬다.
- **배제제약이 깨지는 경우**: 헬스장이 가까운 동네는 공원·산책로도 잘 갖춰져 있어서, 거리가 등록을 거치지 않고도 체중에 직접 영향을 준다. 교육 사례로 옮기면 대학까지의 거리를 도구변수로 쓸 때 대학 근처 지역의 임금 수준 자체가 높을 수 있다.
- **외생성이 깨지는 경우**: 건강에 관심이 많은 사람이 애초에 헬스장 근처로 이사했다면 거리는 U와 상관되고, 이때 Z는 도구변수가 아니라 U의 대리변수가 된다.

배제제약은 증명할 수 없으므로 다음 순서로 쓴다. 먼저 Z가 Y로 직접 갈 수 있는 경로를 숨기지 않고 나열하고, 그 경로가 작동한다면 데이터에 어떤 흔적이 남을지 적은 다음, 그 흔적이 보이지 않는다는 약한 증거를 제시한다. 세 번째 단계에 쓰는 보조 점검은 세 가지다.

- **플라시보 결과변수**: 정책이 영향을 줄 이유가 없는 결과에도 효과가 나오면 위험 신호다.
- **플라시보 시점**: 정책 시행 이전 기간에도 효과가 보이면 위험 신호다.
- **대체 표본**: 직접 경로가 의심되는 집단을 빼도 결론이 유지되는지 확인한다.

이 셋을 통과해도 배제제약이 증명된 것은 아니지만, 깨질 때는 대개 여기서 먼저 티가 난다.

### 코드로 해 보기

세 조건 중 데이터로 확인되는 것은 관련성 하나다. Z를 통제변수와 함께 넣어 D에 회귀하고 Z의 계수와 t값을 본다.

```python
import pandas as pd, statsmodels.formula.api as smf
df = pd.read_csv('practice/chapter06/data/6-1-iv-data.csv')
fs = smf.ols('D ~ Z + X1 + X2', data=df).fit()

print(fs.params['Z'], fs.tvalues['Z'])   # 0.610, 26.31
```

_전체 코드는 practice/chapter06/code/6-1-traditional-2sls.py 참고_

### 결과를 읽는 법

계수 0.610은 Z가 1 늘 때 D가 0.610 늘어난다는 뜻이고, t값 26.31은 이 관계가 우연히 나올 값이 아니라는 뜻이다. 판정은 이렇게 한다. **계수가 0 근처이거나 t값이 2를 넘지 못하면 관련성 조건이 깨진 것이므로, 그 Z로는 2SLS를 돌리지 않고 다른 도구변수를 찾는다.** 여기서는 두 값 모두 충분히 크므로 다음 단계로 넘어간다. 관련성의 정식 판정 기준인 F통계량은 6.4에서 다룬다.

## 6.3 2SLS: 두 번 회귀하는 이유

### 왜 필요한가

도구변수를 찾았어도, Z를 그대로 Y에 회귀하면 "Z의 효과"가 나올 뿐 우리가 원하는 "D의 효과"가 나오지 않는다. D 안에서 Z가 만든 변동만 따로 떼어 낸 다음 그 부분으로 Y를 설명해야 하는데, 이 두 작업을 회귀 두 번으로 나눈 것이 **2SLS**(Two-Stage Least Squares)다.

### 무엇을 계산하는가

**1단계**에서 Z와 X로 D를 예측한다.

```
D = π0 + π1·Z + π2·X + ν     →  예측값 D_hat
```

**2단계**에서 D 대신 D_hat으로 Y를 설명한다.

```
Y = β0 + β1·D_hat + β2·X + ε  →  β1이 인과효과 추정치
```

![그림 6-3. 2SLS의 두 단계](../diagrams/6-3.png)

**비유: 정수기 필터.** 1단계는 정수기 필터와 같은 역할을 하는데, 무엇이 무엇에 대응하는지 밝혀야 비유가 성립한다.

**표 6.5** 정수기와 2SLS의 속성 대응

| 정수기 | 2SLS |
|--------|------|
| 수돗물 원수 | 원래 처치변수 D |
| 물에 섞인 불순물 | D 안에서 U와 상관된 변동 |
| 필터 | 1단계 회귀 `D ~ Z + X` |
| 필터를 통과한 물 | 예측값 D_hat |
| 필터 통과량 | 1단계 F통계량·부분 R² |
| 거른 물로 요리한 결과 | 2단계 회귀 계수 β1 |

이 비유는 여기까지만 맞다. 정수기는 불순물만 걸러 내고 물의 양은 거의 그대로지만, 1단계는 불순물과 함께 정보량도 함께 버린다. 얼마나 버리는지는 아래에서 숫자로 확인한다.

### 코드로 해 보기

1단계가 실제로 U와의 연결을 끊었는지는 상관계수 두 개로 확인된다.

```python
import numpy as np, pandas as pd, statsmodels.formula.api as smf
df = pd.read_csv('practice/chapter06/data/6-1-iv-data.csv')
fs = smf.ols('D ~ Z + X1 + X2', data=df).fit()

print(np.corrcoef(df.D, df.U)[0, 1])              # 0.527
print(np.corrcoef(fs.fittedvalues, df.U)[0, 1])   # 0.001
```

_전체 코드는 practice/chapter06/code/6-1-traditional-2sls.py 참고_

### 결과를 읽는 법

```
Corr(D,     U) = 0.527   ← 원래 D는 U와 강하게 붙어 있다
Corr(D_hat, U) = 0.001   ← 1단계를 거친 D_hat은 U와 사실상 무관하다
```

판정 기준은 두 번째 값이다. **`Corr(D_hat, U)`가 0 근처면 1단계가 제 일을 한 것이고, 여전히 크면 Z가 U와 상관되어 있다는 뜻이므로 외생성 조건을 다시 따져야 한다.** 실제 연구에서는 U를 관측할 수 없어 이 확인을 할 수 없으니, 여기서 그 원리를 눈으로 익혀 두고 실전에서는 Z가 외생적이라는 제도적 근거로 대신한다.

걸러 내면 잃는 것도 있다. D의 표준편차는 0.988인데 D_hat의 표준편차는 0.678이므로, 변동의 약 47%만 남았다(1단계 R² = 0.471). 남은 47%는 깨끗하지만 버린 53%만큼 정보가 줄었으므로, 2SLS의 표준오차는 OLS보다 거의 항상 크다. **편향을 줄이는 대가로 정밀도를 내주는 거래**이며, 그 크기를 아래 실습에서 확인한다.

## 6.4 진단: 이 도구변수를 믿어도 되는가

### 왜 필요한가

Z가 D를 거의 못 움직이는데도 2SLS는 오류 없이 숫자를 뱉는다. 이 상태를 **약한 도구변수**(weak instrument)라 부르며, 이때 나온 추정치는 OLS보다 나쁠 수 있으므로 추정값을 읽기 전에 반드시 걸러야 한다.

### 무엇을 계산하는가

**F통계량**은 "Z가 D를 얼마나 확실히 움직이는가"를 하나의 숫자로 요약한다. 1단계 회귀에서 도구변수의 계수가 모두 0이라는 가설을 검정한 값이며, 실무 기준선은 **10**이다.

**표 6.9** 1단계 F통계량의 판정 기준

| F통계량 | 판정 | 다음 행동 |
|---------|------|----------|
| 10 미만 | 약한 도구변수 | 추정치를 신뢰하지 않는다. 다른 Z를 찾는다 |
| 10~30 | 보통 | 약한 IV에 강건한 신뢰구간을 함께 보고 |
| 30 초과 | 강함 | 통상적 추론 사용 가능 |

F가 기준선 아래로 내려가면 세 가지가 동시에 일어난다. 추정치의 표준오차가 커져 표본을 조금만 바꿔도 값이 크게 달라지고, 표본이 유한할 때 편향이 남아 표본을 늘려도 잘 줄지 않으며, 그런데도 표준오차와 p값은 여전히 그럴듯한 숫자로 나온다. 세 번째가 문제다. 오류 표시가 없으므로 F를 직접 보지 않으면 알 수 없다.

### 코드로 해 보기

```python
import statsmodels.formula.api as smf
first_stage = smf.ols('D ~ Z + X1 + X2', data=df).fit()
print(first_stage.tvalues['Z'] ** 2)      # 도구변수가 하나면 t의 제곱이 F다
```

도구변수가 하나면 t값을 제곱하면 되고, 전용 패키지를 쓰면 `res.first_stage`로 부분 F와 부분 R²를 한 번에 받는다.

_전체 코드는 practice/chapter06/code/6-8-iv2sls-report.py 참고_

### 결과를 읽는 법

1부에서 이미 두 숫자를 얻었다. 실습 1의 F통계량은 **295.05**이고, 실습 2가 자동 출력한 부분 F는 **732.40**, 부분 R²는 **0.410**이다. 두 값 모두 기준선 10을 크게 넘으므로 관련성 조건은 충족이며, 1부의 결과표를 그대로 보고할 수 있다.

**판정 규칙은 하나다. F가 10 미만이면 그 추정치는 쓰지 않고 다른 도구변수를 찾는다.** 억지로 해석하려 들면 OLS보다 나쁜 값을 보고하게 된다. F가 10에서 30 사이면 추정값을 쓰되 약한 IV에 강건한 신뢰구간을 함께 싣는다.

함께 볼 지표가 두 가지 더 있다. **부분 R²**는 X를 통제한 뒤에도 Z가 추가로 설명하는 D의 변동이며 여기서는 0.410이다. **표준오차의 종류**는 지역·학교·기업처럼 묶인 단위가 있으면 클러스터 강건 방식으로 바꾸고, 무엇을 썼는지 표 아래에 반드시 적는다.

## 6.5 LATE: 이 숫자는 누구의 효과인가

### 왜 필요한가

F통계량을 통과했다고 해서 그 숫자가 전체 인구의 평균 효과인 것은 아니다. 정책 대상을 잘못 잡는 오류가 여기서 생기므로, 추정치를 보고하기 전에 그것이 누구의 효과인지 규정해야 한다.

### 무엇을 계산하는가

쿠폰(Z)을 뿌려서 앱 구독(D)을 유도하고 이용시간(Y)을 본다고 하자. 사람은 넷으로 나뉜다.

**표 6.10** 도구변수에 대한 반응으로 나눈 네 유형

| 유형 | 쿠폰 없을 때 | 쿠폰 있을 때 | 설명 |
|------|-------------|-------------|------|
| 순응자(complier) | 구독 안 함 | 구독함 | 쿠폰 때문에 행동이 바뀐 사람 |
| 항상수용자(always-taker) | 구독함 | 구독함 | 쿠폰과 무관하게 원래 구독할 사람 |
| 절대거부자(never-taker) | 구독 안 함 | 구독 안 함 | 쿠폰을 줘도 안 할 사람 |
| 반항자(defier) | 구독함 | 구독 안 함 | 쿠폰 때문에 오히려 안 함(보통 없다고 가정) |

Z가 바뀌어도 행동이 안 바뀌는 사람은 데이터에 인과 정보를 주지 못하므로, **2SLS가 재는 것은 순응자의 평균 효과**다. 이것을 **LATE**(Local Average Treatment Effect)라고 부른다.

**비유: 그물코 크기가 정해진 어망.** 어망을 던져 잡힌 물고기의 평균 무게를 재면 그 값은 바다 전체 물고기의 평균 무게가 아니다. 그물코보다 작은 물고기는 빠져나가고, 그물을 찢을 만큼 큰 물고기는 애초에 걸리지 않는다.

**표 6.11** 어망과 도구변수의 속성 대응

| 어망 | 도구변수 |
|------|----------|
| 그물코 크기 | 도구변수 Z의 종류와 세기 |
| 그물에 걸린 물고기 | 순응자 |
| 코를 빠져나간 작은 물고기 | 절대거부자 |
| 그물을 찢고 나간 큰 물고기 | 항상수용자 |
| 잡힌 물고기의 평균 무게 | LATE 추정값 |
| 그물코를 바꾸면 평균도 바뀜 | 도구변수를 바꾸면 LATE도 바뀜 |

이 비유는 여기까지만 맞다. 어망은 어떤 물고기가 빠져나갔는지 바다를 조사해 확인할 수 있지만, 순응자가 누구인지는 개인 단위로 식별되지 않는다. 순응자의 비율과 특성을 집계 수준에서 짐작할 뿐이다.

### 결과를 읽는 법

**도구변수를 바꾸면 추정값이 바뀌는 것이 정상이다.** 같은 교육 수익률을 재도 "대학까지 거리"를 쓴 연구와 "출생 분기"를 쓴 연구의 값이 다른 까닭이 여기 있으며, 둘 중 하나가 틀린 것이 아니라 순응자 집단이 서로 다르다.

대학까지의 거리를 도구변수로 쓴 교육 수익률 연구에서 순응자는 "대학이 가까워서 진학했지만 멀었으면 진학 안 했을 사람"이므로, 대체로 진학 여부가 아슬아슬했던 층이다. 따라서 이 추정치는 전체 국민의 대학 효과가 아니고, 성적이 아주 좋아 어디든 진학했을 사람에게는 적용되지 않는다. "대학 정원을 늘리면"처럼 한계선상 학생을 움직이는 정책에는 잘 맞지만 "모든 국민이 대학을 나오면"에는 맞지 않는다.

판정 규칙은 보고서 문장으로 옮긴다. 추정치를 실을 때 다음 문장을 함께 넣고, 순응자가 어떤 사람인지 한 문단으로 서술한다.

> **"이 추정치는 도구변수에 반응해 처치가 바뀐 집단의 효과다."**

## 6.6 2SLS가 잘 맞지 않는 세 경우

### 왜 필요한가

지금까지는 D와 Y의 관계가 직선이고, 통제변수가 적으며, 효과가 모두에게 같다고 가정했다. 세 가정 중 하나라도 깨지면 F통계량이 아무리 커도 추정치가 어긋나므로, 어떤 상황에서 무엇이 깨지는지 알아 두어야 한다.

### 무엇을 계산하는가

**첫째, D와 Y의 관계가 곡선일 때.** 참 관계가 `Y = 2 + 3D + 0.5D²`라면 D를 1 늘렸을 때의 효과는 `3 + D`이므로 D 값에 따라 달라진다. D가 1일 때 한계효과는 4, D가 3일 때는 6인데, 선형 2SLS는 이 차이를 하나의 숫자로 뭉갠다.

**둘째, 통제변수가 많을 때.** 편의점 매출을 분석하는데 쓸 수 있는 변수가 날씨·요일·시간대·기온·강수량·근처 행사·경쟁점 거리·유동인구 등 50개라고 하자. 매출은 변수 하나하나보다 조합에서 갈리므로("비 오는 금요일 저녁"은 셋을 따로 더한 것과 다르다) 상호작용 항을 넣어야 하는데, 두 개짜리 조합만 해도 50×49/2 = 1,225개다. 표본이 500일치라면 추정할 항이 관측치보다 두 배 넘게 많다. 사람이 항을 고르면 자의성이 들어가고, 잘못 고르면 모형 오설정 편향이 생기며, 다 넣으면 과적합된다.

**셋째, 효과가 사람마다 다를 때.** 국비 지원 코딩 교육의 수료생 전체 취업률 상승분이 8%p로 나왔다고 해서 이 값이 모든 참가자에게 해당하지는 않는다. 비전공 20대에게는 15%p 오를 수 있고, 관련 경력이 있는 30대에게는 2%p에 그칠 수 있으며, 50대 전직 희망자에게는 효과가 없을 수도 있다. 예산이 한정되어 있다면 어느 집단에 먼저 넣을지 정해야 하는데, 전통 2SLS는 LATE 하나만 주므로 "쓸까 말까"는 알려 주지만 "누구에게 먼저 쓸까"는 알려 주지 않는다.

**결과를 읽는 법.** 참값 3.800이 어디서 나왔는지부터 확인한다. 참 관계가 `Y = 2 + 3D + 0.5D²`이므로 D를 1 늘렸을 때의 효과는 `3 + D`이고, 데이터의 평균 D가 0.8이므로 평균 한계효과는 3 + 0.8 = 3.8이다. 즉 이 데이터에서 참값은 하나가 아니라 D=0에서 3.0, D=0.8에서 3.8, D=2에서 5.0, D=4에서 7.0으로 달라진다.

**표 6.12** 실습 3의 세 추정값 비교

| 방법 | 추정값 | 참값 3.800 대비 |
|------|--------|-----------------|
| OLS | 2.821 | -25.8% |
| 선형 2SLS | 4.447 | **+17.0%** |
| 2SLS + D² 항 추가 | 3.870 | +1.8% |

- **선형 2SLS가 위로 어긋난 이유**: Z 자체가 `0.3*Z²` 때문에 큰 값에서 D를 더 크게 밀어 올리므로, 도구변수가 만든 변동이 D가 큰 구간(한계효과가 큰 구간)에 몰린다. 그래서 평균보다 큰 값이 나온다. 내생성은 잡았지만 곡선을 못 잡은 상태다.
- **OLS가 아래로 어긋난 이유**: 내생성 때문이며, 절대값으로는 OLS(25.8%)가 선형 2SLS(17.0%)보다 더 나쁘다.
- **D² 항 하나로 회복된 정도**: `D` 계수 3.125(참값 3.0)와 `D²` 계수 0.465(참값 0.5) 모두 참값 근처이고 오차가 17.0%에서 1.8%로 줄었다.

여기서 정할 행동 규칙이 있다. **곡선이 의심되면 먼저 다항항을 넣어 본다.** 딥러닝은 어떤 형태인지 짐작조차 안 될 때 꺼내는 도구다.

**RESET 검정이 판정 도구다.** RESET은 "선형 모형이 맞는가"를 묻는 검정이며, F가 791.60이고 p가 0.001 미만이면 선형 가정을 기각한다. 참값을 모르는 실제 연구에서도 돌릴 수 있으므로, 곡선을 의심할 근거로 이 값을 쓴다.

```python
from statsmodels.stats.diagnostic import linear_reset
print(linear_reset(model, power=2, use_f=True))
```

판정 기준은 이렇다. **p값이 0.05 미만이면 선형 모형을 그대로 보고하지 않고 D² 항을 넣어 다시 추정한다.**

마지막 [6단계] 출력은 앞에서 말한 고차원 문제를 숫자로 보인 것이다. 공변량 50개에서 나오는 2차 상호작용 1,225개를 표본 500개로 추정할 수 없다.

## 6.7 DeepIV: 곡선 모양을 모를 때

### 왜 필요한가

실습 3에서 확인했듯 관계가 곡선이면 `D²` 항을 넣어 오차를 17.0%에서 1.8%로 줄일 수 있다. 문제는 곡선 모양을 짐작조차 못 할 때다. 2차인지 3차인지, 어느 구간에서 꺾이는지 모르면 넣을 항을 고를 수 없다.

### 무엇을 계산하는가

DeepIV는 그 항을 사람이 고르지 않고 데이터에서 찾게 한다. 2SLS의 1단계·2단계 뼈대는 그대로 두고 직선 가정만 걷어내며, 바꾼 부분은 1단계 하나다.

전통 1단계는 D의 **평균**만 2단계로 넘기는데, D가 두 무리로 갈라져 있으면 평균은 그 사이 빈 공간을 가리킨다. 어떤 지역의 주당 근무시간(D)이 주 20시간(시간제)과 주 45시간(전일제)으로 갈라져 있다면 평균은 32.5시간이지만 실제로 32시간 일하는 사람은 거의 없으므로, 평균만 넘기면 아무도 해당하지 않는 값으로 효과를 계산하게 된다.

**비유: 배달앱의 도착 예정시간.**

**표 6.13** 도착시간 안내와 IV 1단계의 속성 대응

| 배달 도착시간 안내 | IV 1단계 |
|--------------------|----------|
| "35분"이라고 한 숫자만 표시 | 전통 2SLS가 넘기는 평균값 |
| "25~60분, 30분에 몰림" | DeepIV가 넘기는 범위 |
| 비 오는 날은 빠른 배달과 늦은 배달로 갈림 | 조건에 따라 D가 두 무리로 갈림 |
| 두 무리를 평균 내면 45분 | 아무도 해당 안 되는 값 |

이 비유는 여기까지만 맞다. 배달 시간은 실제 도착 기록으로 분포를 직접 확인할 수 있지만, DeepIV의 1단계 분포는 관측이 아니라 모형이 추정한 값이므로 학습이 잘못되면 분포 자체가 틀린다. 기억할 문장은 하나다. **DeepIV는 "D의 평균"이 아니라 "D가 나올 법한 범위"를 배운다.**

- **`참값 ATE: 3.383`** — 실습 1의 3.42와 다르다. 이 스크립트는 자체적으로 데이터를 만들며 관계도 다르므로 두 실습의 숫자를 직접 비교하지 않는다.
- **`Stage 1 R²: 0.360`** — Z와 X로 D를 예측한 설명력이 36%다. 낮아 보이지만 IV에서는 이 값이 낮은 것이 정상이며, 100%에 가까우면 D가 사실상 Z의 함수라는 뜻이어서 D의 자체 변동이 없어 2단계가 성립하지 않는다.
- **`DeepIV 3.330(오차 1.6%) 대 2SLS 4.180(오차 23.6%)`** — 곡선 관계에서 DeepIV가 더 정확하며, 실습 3에서 본 것과 같은 현상이다.
- **`RMSE: DeepIV 1.83 대 2SLS 3.41`** — RMSE는 개별 예측이 실제 Y와 얼마나 떨어져 있는지를 재는 지표로 추정값 정확도와는 다르지만, 여기서는 둘 다 DeepIV가 낫다.

**쓰기 전에 확인할 것이 세 가지다.** 표본이 수천 개 이하면 신경망이 쉽게 과적합되므로 `D²` 항 쪽이 낫고, 1단계가 무너지면 2단계도 함께 무너지므로 1단계 설명력을 먼저 보며, 방향이 크게 다를 때 어느 쪽이 이상한지 따질 수 있도록 2SLS 결과를 항상 함께 싣는다.

**주의: 이 코드는 정식 DeepIV가 아니다.** 스크립트 상단에 명시되어 있듯 교육용 간소화 버전이다.

**표 6.14** 정식 DeepIV와 실습 코드의 차이

| 항목 | 원래 DeepIV | 이 실습 코드 |
|------|-------------|--------------|
| 1단계 | D가 나올 범위 전체를 학습 | 평균만 예측(`MLPRegressor`) |
| 2단계 | 범위에서 D를 여러 번 뽑아 학습 | 예측값 하나만 사용 |

이 코드가 보여 주는 것은 "신경망을 쓰면 곡선을 잡는다"까지이며, 6.7에서 설명한 범위 학습은 들어 있지 않다. 정식 구현이 필요하면 EconML의 `DeepIV`를 쓴다.

## 6.8 IV 환경에서의 이질적 효과(CATE)

### 왜 필요한가

6.6의 세 번째 문제인 이질성을 다룬다. 예산이 한정된 정책에서는 평균 효과보다 "누구에게 먼저 쓸까"가 결정을 좌우하므로, 집단별 효과를 따로 추정해야 한다.

### 무엇을 계산하는가

같은 사람에게 처치를 준 경우와 안 준 경우를 모형에 각각 넣어 두 예측값을 뺀다. 이 차이가 그 사람의 **조건부 평균 처치효과**(CATE)다.

```python
def estimate_cate(model, X):
    n = X.shape[0]
    y1 = model.predict(np.ones((n, 1)), X)    # 모두 대학을 졸업했다고 가정
    y0 = model.predict(np.zeros((n, 1)), X)   # 모두 졸업하지 않았다고 가정
    return y1 - y0                             # 사람마다 다른 효과
```

_전체 코드는 practice/chapter06/code/6-7-education-returns.py 참고_

여기서 자주 터지는 함정이 세 가지다. **외삽**은 데이터에 30~50세만 있었는데 20세의 효과를 뽑는 경우로 근거가 없다. **하위집단 약한 도구변수**는 전체 F통계량이 295여도 특정 지역만 떼면 3으로 떨어질 수 있는 경우이며, 집단별로 1단계를 다시 돌려야 한다. **불확실성**은 집단별 효과의 폭이 넓어 신뢰구간 없이는 순서를 말할 수 없는 경우다.

**결과를 읽는 법.** 여섯 단계를 순서대로 읽는다.

- **`참값 0.130`** — 로그 임금에서 계수 0.130은 임금이 약 13.9% 높다는 뜻인데 `exp(0.130) - 1 = 0.139`이기 때문이다. 계수가 0.2 이하로 작으면 `0.130 → 약 13%`처럼 그냥 읽어도 오차가 크지 않다.
- **`OLS: 0.260, 참값 대비 +99.3%`** — 참값의 두 배다. 능력이 높은 사람이 대학도 가고 임금도 높으므로 능력의 몫까지 대학 몫으로 계산되었으며, 6.1에서 배운 생략변수 편향이 그대로 나타났다.
- **`정원 증가율 계수: 0.0701`** — 1단계 계수는 버리는 숫자가 아니라 "정책이 사람을 얼마나 움직이는가"를 재는 값이다. 정원 증가율이 1%p 높은 지역에서 대졸 확률이 7.01%p 높으며, 6단계 시뮬레이션이 이 값을 그대로 쓴다.
- **`1단계 F: 3266.90`** — 기준선 10을 크게 넘으므로 추정값을 읽어도 된다. 표본이 5만이고 도구변수가 강해서 나온 값이다.
- **`2SLS: 0.131 (SE 0.013), CI [0.106, 0.156]`** — 참값 0.130과 0.5% 차이이고 신뢰구간이 참값을 포함하는데, OLS의 0.260은 이 구간 밖에 한참 있다.

**표 6.16** 실습 5의 두 추정값 비교

| 방법 | 추정값 | 참값 0.130 대비 | 신뢰구간이 참값을 포함하는가 |
|------|--------|------------------|-------------------------------|
| OLS | 0.260 | +99.3% | 아니오 |
| 2SLS | 0.131 | +0.5% | 예 |

**표 6.17** 부모 학력 집단별 효과

| 부모 학력 | 1단계 F | 추정값 | 95% 신뢰구간 | 참값 |
|-----------|---------|--------|--------------|------|
| 중졸 이하 | 1429.1 | 0.070 | [0.033, 0.107] | 0.050 |
| 고졸 | 1246.8 | 0.152 | [0.111, 0.192] | 0.150 |
| 대졸 이상 | 591.1 | 0.222 | [0.163, 0.280] | 0.250 |

집단별 표는 세 가지를 순서대로 본다.

- **집단마다 1단계 F를 다시 계산했다.** 전체 F가 3266이어도 집단을 나누면 표본이 줄어 F가 떨어지며, 대졸 이상 집단은 591로 가장 낮다. 6.8에서 말한 하위집단 약한 도구변수 함정을 실제로 점검한 것이다. **어느 집단의 F가 10 아래로 내려가면 그 집단의 추정값은 보고하지 않는다.**
- **추정 순서가 참값 순서와 일치한다.** 0.070 < 0.152 < 0.222이고 참값도 0.050 < 0.150 < 0.250이다.
- **중졸 이하 [0.033, 0.107]과 대졸 이상 [0.163, 0.280]이 겹치지 않는다.** 그래서 "부모 학력이 높을수록 대졸 프리미엄이 크다"고 말할 수 있다.

세 번째가 판정 규칙이다. **신뢰구간이 겹치면 추정값 순서가 어떻든 차이를 주장하지 않는다.** 집단별 분석에서 가장 자주 어기는 규칙이다.

**정책 시뮬레이션으로 연결한다.**

```
평균 임금 변화 = (늘어난 대졸률) × (대졸 프리미엄)
              = 0.070 × 0.131
              = 0.0092 = 0.92%
```

정원 증가율을 1%p 올리면 대졸률이 7.0%p 오르고 그 결과 평균 임금이 0.92% 오른다. 대졸 프리미엄 14%는 큰 값인데 전체 평균 효과는 1%도 안 되는데, **정책 효과는 "효과 크기"와 "실제로 영향받는 사람 수"의 곱이기 때문이다.** 효과가 커도 움직이는 사람이 적으면 총효과는 작으며, 이것이 정책 보고서에서 가장 자주 빠지는 계산이다.

두 숫자의 출처가 다른 점에 주목한다. 대졸률 변화 7.0%p는 **1단계**에서, 프리미엄 0.131은 **2단계**에서 나왔으므로, 두 단계를 다 돌려야 정책 시뮬레이션이 가능하다.

## 6.9 방법 선택과 결과 보고

### 어떤 방법을 쓸지 정하는 순서

![그림 6-4. 어떤 방법을 쓸지 정하는 순서](../diagrams/6-4.png)

판단 순서는 이렇다. 먼저 1단계 F가 10을 넘는지 보고, 넘지 못하면 어떤 방법을 써도 소용없으므로 도구변수부터 다시 찾는다. F를 통과하면 RESET 검정으로 선형 가정을 점검하고, 기각되면 `D²` 같은 다항항을 넣어 다시 추정한다. 다항항으로도 잡히지 않고 곡선 모양을 짐작할 수 없을 때만 DeepIV 계열로 넘어가며, 이때도 2SLS 결과를 기준값으로 함께 싣는다. 집단별 결정이 필요하면 CATE를 추정하되 집단마다 1단계 F를 다시 계산한다.

### 결과를 어떻게 읽는가

IV 결과표를 받았을 때 읽는 순서는 추정값이 아니라 진단부터다.

1. **1단계 F통계량을 먼저 본다.** 10 미만이면 나머지 숫자를 읽지 않고 보고를 중단한다.
2. **표준오차의 종류를 확인한다.** 손으로 나눈 2단계 값이면 실제보다 15.9% 작을 수 있으므로 전용 패키지 출력인지 확인한다.
3. **신뢰구간이 0을 포함하는지 본다.** 포함하면 "효과가 있다"고 말하지 않는다.
4. **추정값을 LATE로 해석한다.** 순응자가 누구인지 규정하고, 그 집단에 해당하는 정책 결론만 쓴다.
5. **효과 크기에 영향받는 사람 수를 곱한다.** 이 곱이 정책의 총효과이며, 개별 효과 크기만으로 결정하지 않는다.

### 실무 적용 점검표

**설계 단계에서 확인한다.**

- Z가 D를 움직이는 제도적 이유를 한 문장으로 쓸 수 있는가
- Z가 Y로 직접 갈 수 있는 경로를 세 개 이상 나열하고 각각 반박했는가

**진단 단계에서 확인한다.**

- 1단계 F통계량, 부분 R², Z의 계수와 t값을 표에 넣었는가
- 관계가 곡선일 가능성을 RESET 검정으로 확인했는가
- 클러스터 구조가 있다면 표준오차 종류를 명시했는가

**해석 단계에서 확인한다.**

- 순응자가 어떤 사람인지 한 문단으로 설명했는가
- 결론을 전체 평균이 아니라 순응자 효과로 서술했는가
- 2SLS와 다른 방법의 결과 방향이 일치하는지 보고했는가

**표 6.18** 자주 나는 오류 여섯 가지

| 오류 | 왜 문제인가 | 대신 할 것 |
|------|-------------|-----------|
| 1단계 F를 보고하지 않음 | 약한 IV면 결과 전체가 무의미 | F, 부분 R², Z의 t값을 표에 넣는다 |
| 손으로 2단계를 돌리고 표준오차를 그대로 씀 | 1단계 추정 불확실성이 빠짐 | `linearmodels.IV2SLS`를 쓴다 |
| LATE를 ATE처럼 말함 | 정책 대상이 달라짐 | "도구변수에 반응한 집단의 효과"를 명시 |
| 배제제약을 한 줄로 끝냄 | 독자가 가장 의심하는 지점 | 직접 경로를 3개 나열하고 각각 반박 |
| 신경망 결과만 제출 | 어디서 틀어졌는지 확인할 기준이 없음 | 2SLS 결과를 기준값으로 함께 싣는다 |
| 하위집단 분석에서 1단계 점검 생략 | 전체는 강해도 집단별로 약할 수 있음 | 집단별 F를 다시 계산 |

## 핵심 정리

1. **내생성**은 처치 D가 관측 안 되는 원인 U와 함께 움직이는 상태이며, OLS는 오류 표시 없이 어긋난다(실습 1에서 36.5% 차이). 편향은 (U의 Y 효과) × (D와 U의 연결 강도) = -1.946 × 0.625 = -1.216으로 계산되고, 방향은 두 부호의 곱으로 정해진다.
2. **도구변수 3조건**은 관련성·배제제약·외생성이며, 데이터로 검증되는 것은 관련성 하나뿐이다.
3. **2SLS 1단계**가 하는 일은 상관계수 두 개로 확인된다. `Corr(D, U) = 0.527`이 `Corr(D_hat, U) = 0.001`로 바뀐다.
4. **1단계 F가 10 미만이면** 추정하지 않고 다른 도구변수를 찾는다. 표준오차가 커지고 편향이 남는데도 겉으로는 정상으로 보이기 때문이다.
5. **보고서에는 전용 패키지 결과를 쓴다.** 손으로 나눈 2단계는 표준오차가 15.9% 작게 나오며, 추정값은 같고 표준오차만 다르다(실습 2).
6. **2SLS가 재는 것은 LATE**, 곧 도구변수에 반응해 행동이 바뀐 사람들의 평균 효과다.
7. **2SLS가 잘 맞지 않는 세 경우**는 비선형·고차원·이질성이다. 곡선이면 먼저 다항항을 넣어 본다(실습 3에서 17.0% → 1.8%).
8. **DeepIV는 곡선 모양을 짐작조차 못 할 때만 꺼낸다.** 1단계·2단계 뼈대는 그대로 두고 직선 가정만 걷어내며, 모양을 알면 D² 항이 더 빠르고 정확하다.
9. **집단별 효과는 신뢰구간이 겹치지 않을 때만 순서를 말한다.** 실습 5에서 중졸 이하 [0.033, 0.107]과 대졸 이상 [0.163, 0.280]이 겹치지 않았고, 집단마다 1단계 F를 다시 계산했다.
10. **정책 효과는 효과 크기 × 영향받는 사람 수**다. 실습 5에서 프리미엄이 14%인데 정원 1%p 확대의 평균 임금 효과는 0.92%였다.

## 연습 문제

1. 실습 1에서 OLS 신뢰구간 [2.043, 2.298]은 참값 3.42를 포함하지 않는데도 OLS 계수는 "통계적으로 유의"하게 나온다. 유의성과 정확성이 왜 다른 것을 재는지 설명하고, 이 구분을 보고서에서 어떻게 표현할지 한 문장으로 쓰라.
2. 어떤 연구가 1단계 F통계량 3.2를 보고하면서 2SLS 추정값과 p값을 함께 실었다. 이 결과를 어떻게 판정하고, 연구자에게 무엇을 요구할지 쓰라.
3. 실습 3에서 선형 2SLS 편향은 양수(+17.0%)이고 OLS 편향은 음수(-25.8%)다. 두 편향의 원인이 서로 다른데 각각 무엇이며, 어느 진단으로 각각을 잡아내는가.
4. 같은 교육 수익률을 재는데 "대학까지 거리"를 쓴 연구는 0.09, "출생 분기"를 쓴 연구는 0.13을 보고했다. 어느 쪽이 틀렸다고 말할 수 없는 이유를 LATE 개념으로 설명하고, 두 값을 정책 보고서에 어떻게 함께 실을지 쓰라.
5. 실습 5에서 정원 증가율을 1%p가 아니라 3%p 올린다면 평균 임금 변화는 얼마가 되는가. 계산 과정을 쓰고, 이 계산에 숨어 있는 가정을 두 개 이상 지적하라.
