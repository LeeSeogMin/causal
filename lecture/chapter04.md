## 4.1 전통적 이중차분법(Difference-in-Differences) 📊

### "다이어트 약 효과 측정법" - DID의 기본 아이디어

이중차분법(DID)은 **"전후 비교"와 "그룹 간 비교"를 동시에 하는 방법**이다. Card & Krueger(1994)의 최저임금 연구로 유명해진 이 방법은 준실험설계의 대표적 도구다.

**💊 비유로 이해하기: 다이어트 약 효과**

다이어트 약의 효과를 알고 싶다고 하자. 단순히 "약 먹은 사람이 3kg 빠졌다"고 해서 약 효과가 3kg은 아니다. 그 사람이 운동도 했을 수 있고, 계절적으로 모든 사람이 살이 빠지는 시기일 수도 있다. 이중차분법은 이렇게 계산한다:

```
(약 먹은 그룹의 체중 변화) - (안 먹은 그룹의 체중 변화) = 약의 순수 효과
```

**첫 번째 차분**: 각 그룹 내에서 "전후" 변화를 계산 → 개인의 체질 같은 고정 특성이 제거됨
**두 번째 차분**: 두 그룹의 변화량 차이를 계산 → 계절 효과 같은 공통 시간 추세가 제거됨

비즈니스에서는 **"특정 지역(서울)에만 TV 광고를 송출했을 때, 광고의 순수 매출 기여분(Lift)"**을 추정하는 데 활용된다. 광고 기간 동안 서울의 매출 증가분에서, 광고를 하지 않은 부산(대조군)의 자연 매출 증가분을 빼줌으로써 계절성이나 경기 변동 효과를 발라낼 수 있다.

### 이원 고정효과 모형(TWFE)

패널 데이터(같은 개체를 여러 시점에서 관찰한 데이터)에서 DID를 추정하는 표준 방법이 이원 고정효과 모형이다.

Yᵢₜ = αᵢ + λₜ + δ·Dᵢₜ + εᵢₜ

- **αᵢ (개체 고정효과)**: 각 개체(도시, 기업)마다 고유한 특성을 통제 (서울은 원래 매출이 높다 등)
- **λₜ (시간 고정효과)**: 모든 개체에 공통인 시간 추세를 통제 (경기 변동, 계절 효과 등)
- **δ (처치효과)**: 이것이 우리가 알고 싶은 **정책의 순수 효과**

### DID의 핵심 가정 - 평행추세

DID가 작동하려면 **"정책이 없었다면 두 그룹이 비슷하게 변했을 것"**이라는 **평행추세 가정(parallel trends assumption)**이 필요하다. 비유하면 "다이어트 약을 먹지 않았다면 두 그룹 모두 비슷한 속도로 체중이 변했을 것"이라는 가정이다. 이 가정이 틀리면 DID 결과도 틀린다.

문제는 이 가정을 완벽히 검증할 수 없다는 것이다. 정책이 없었을 때의 결과는 관측할 수 없기 때문이다. 대신 **사전 추세 검정(pre-trend test)**으로 "정책 전에 두 그룹이 비슷하게 변했는지" 간접적으로 확인한다.

### DID의 한계

**첫째**, 이질적 처치효과와 엇갈린 처치 시점(staggered adoption) 문제. 여러 지역에 정책이 다른 시점에 적용되면, 전통적 TWFE는 편향된 결과를 줄 수 있다. Goodman-Bacon(2021)이 이 문제를 지적했고, Callaway & Sant'Anna(2021) 등이 대안을 제시했다.

**둘째**, 선형 모형 가정. 처치효과가 비선형이거나, 공변량과 복잡한 상호작용이 있으면 기본 모형으로는 포착이 어렵다.

## 4.2 이중 기계학습(DML)과 DID 확장 🤖

### "방해요소를 AI로 걸러내기" - DML-DID의 아이디어

전통적 DID는 공변량(방해요소)을 선형적으로만 통제한다. 하지만 현실에서는 "소득 수준 × 산업 구조"의 조합 효과처럼 비선형적인 관계가 많다. Chernozhukov et al.(2018)의 **이중 기계학습(DML)**은 이런 복잡한 방해요소를 머신러닝으로 걸러내는 방법이다.

**🧹 비유: "깨끗한 비교를 위한 2단계 세탁"**

DML-DID는 세탁에 비유할 수 있다:

**1차 세탁 - 결과변수 정화**: "정책이 없었다면 이 도시의 매출이 얼마였을까?"를 머신러닝으로 예측하고, 실제 매출에서 이 예측값을 뺀다. 이렇게 하면 다른 요인들의 영향이 제거된 "순수한 매출 변화"만 남는다.

**2차 세탁 - 처치변수 정화**: "이 도시가 정책을 받을 확률은 얼마였나?"를 머신러닝으로 예측하고, 실제 정책 여부에서 이 확률을 뺀다. "예상 밖의 정책 적용"만 남는다.

**최종 비교**: 두 "세탁된" 값의 관계를 분석하면, 방해요소가 모두 제거된 상태에서 순수한 정책 효과만 측정할 수 있다.

핵심은 머신러닝이 **비선형 관계**(예: "특정 소득 구간에서만 효과가 급증")를 자동으로 포착한다는 점이다. 전통 방법은 연구자가 이런 패턴을 미리 지정해야 하지만, DML은 데이터에서 자유롭게 학습한다.

### 교차 적합(Cross-fitting)의 중요성

같은 데이터로 "세탁"과 "효과 추정"을 동시에 하면 과적합 편향이 생긴다. 이를 방지하기 위해 데이터를 K개(보통 5개)로 나누어, "세탁"은 다른 부분의 데이터로, "효과 추정"은 현재 부분으로 수행한다. 이것이 **K-fold 교차 적합**이다.

### 💻 실습: DML-DID 추정하기

아래 코드는 50개 고차원 공변량이 있는 복잡한 데이터에서 DML-DID를 추정한다.

```python
# DML for DID (5-fold 교차 적합)
for train_idx, test_idx in kf.split(df):

    # Nuisance parameter 학습

    rf_outcome.fit(X_train[d_train==0], y_train[d_train==0])
    rf_treat.fit(X_train, d_train)

    # 직교화된 모멘트로 θ 추정

    y_res = y_test - rf_outcome.predict(X_test)

    d_res = d_test - rf_treat.predict(X_test)
    theta_estimates.append(np.sum(y_res * d_res) / np.sum(d_res**2))
```

### DR-DID: "보험을 든 DID" 🛡️

Sant'Anna & Zhao(2020)의 **DR-DID(Doubly Robust DID)**는 두 가지 모형을 동시에 사용한다.

| 결과 회귀 모형 | 성향점수 모형 |        추정 결과         |
| :------------: | :-----------: | :----------------------: |
|     ✓ 정확     |   ✗ 부정확    |        ✓ 일치추정        |
|    ✗ 부정확    |    ✓ 정확     |        ✓ 일치추정        |
|     ✓ 정확     |    ✓ 정확     | ✓ 일치추정 (효율성 최고) |
|    ✗ 부정확    |   ✗ 부정확    |       ✗ 편향 발생        |

**핵심**: 두 모형 중 **하나만 맞아도** 정확한 추정이 가능하다. 마치 보험처럼, 하나가 틀려도 다른 하나가 보완해준다.

```python
# DR-DID 구현 (Sant'Anna & Zhao 2020)
from sklearn.ensemble import RandomForestClassifier, RandomForestRegressor

# 1단계: 성향점수 추정 (처치 확률)
ps_model = RandomForestClassifier(n_estimators=100, max_depth=5)

ps_model.fit(X, D)
ps_scores = ps_model.predict_proba(X)[:, 1]

# 2단계: 결과 회귀 추정 (대조군만 사용)
outcome_model = RandomForestRegressor(n_estimators=100, max_depth=5)

outcome_model.fit(X[D==0], Y[D==0])
mu_0 = outcome_model.predict(X)

# 3단계: DR-DID 추정량 계산
weights = D / ps_scores  # 역확률 가중

dr_did_treated = np.mean(weights * (Y - mu_0) * (D == 1))

dr_did_control = np.mean(weights * (Y - mu_0) * (D == 0))
tau_dr = dr_did_treated - dr_did_control
```

## 4.3 합성통제법(Synthetic Control Method) 🧪

### "가짜 서울 만들기" - SCM의 기본 아이디어

DID는 대조군이 여러 개 있을 때 잘 작동한다. 하지만 **정책이 한 곳(예: 서울)에만 적용**되었다면? 비교할 대조군을 어떻게 정할까?

Abadie & Gardeazabal(2003)이 제안한 **합성통제법(SCM)**은 "가짜 서울"을 만든다. 부산, 대구, 인천 등 여러 도시를 적절한 비율로 섞어서, 정책 시행 전 서울과 거의 똑같은 패턴을 보이는 합성 도시를 만드는 것이다.

**🎨 비유: 물감 섞기**

빨간색을 만들고 싶은데 빨간 물감이 없다면? 다른 색들을 적절히 섞어서 빨간색에 가깝게 만들 수 있다. SCM도 마찬가지로, 여러 도시를 섞어서 서울에 가장 가까운 "합성 서울"을 만든다.

**예시**: "부산 30% + 대구 50% + 인천 20%" = 합성 서울

**핵심 제약**:
- 각 도시의 가중치는 0 이상 (음수 가중치 안 됨)
- 모든 가중치의 합은 100%
- 정책 시행 전에 합성 서울이 진짜 서울과 최대한 비슷해야 함

정책 효과는 간단하다: **진짜 서울 결과 - 가짜 서울 결과**

### SCM의 품질 평가

합성 대조군이 얼마나 잘 만들어졌는지 두 가지로 확인한다:

**MSPE/RMSPE**: "정책 전에 가짜 서울이 진짜 서울을 얼마나 잘 흉내 냈는가." 값이 작을수록 좋다. RMSPE가 결과 변수 표준편차의 30% 이내면 합격이다.

**HHI (가중치 집중도)**: 가중치가 골고루 퍼져 있는지 확인한다. HHI < 0.3이면 여러 도시가 골고루 기여하는 것이고, 0.7 넘으면 특정 도시에 과도하게 의존하여 신뢰도가 낮다.

### 💻 실습: SCM으로 정책 효과 추정하기

아래 코드는 한 처치 도시와 20개 대조 도시의 가상 데이터로 합성통제법을 구현한다.

```python
# SCM 최적 가중치 계산 (핵심 로직)
# 목적 함수: 사전 기간 MSPE 최소화
scm_objective = lambda w: np.sum((Y_treated_pre - Y_donors_pre @ w)**2)

# 제약: Σwⱼ=1, wⱼ≥0
constraints = {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
result = minimize(scm_objective, w_init,
                 constraints=constraints, bounds=[(0,1)]*n_donors)

# 처치효과: 처치군 - 합성대조군
treatment_effect = Y_treated_post - Y_donors_post @ result.x
```

## 4.4 합성 이중차분법(SDID) ⚡

### "DID + SCM = 최강 조합" - SDID의 아이디어

DID는 "평행추세"를 가정하고, SCM은 "완벽한 사전 적합"을 가정한다. 둘 다 완벽하지 않다면? Arkhangelsky et al.(2021)이 제안한 **SDID(합성 이중차분법)**은 두 방법의 장점을 결합한다.

**🛡️ 비유: "투자 포트폴리오의 분산"**

한 종목에 몰빵하면 위험하듯이, 한 가정에만 의존하면 위험하다. SDID는 두 가정에 "분산 투자"하는 것이다:

- **DID의 장점**: 전후 비교를 통한 시간 효과 제거
- **SCM의 장점**: 최적 가중치로 유사한 대조군 구성

SDID는 **단위 가중치**(어떤 대조 도시를 얼마나 쓸지)와 **시간 가중치**(어떤 시점에 더 주목할지)를 동시에 최적화한다.

**핵심 장점 - 이중 강건성**: 평행추세가 완벽하면 DID처럼, 사전 적합이 완벽하면 SCM처럼, 둘 다 부분적이면 둘의 정보를 균형 있게 통합한다. **어느 한 가정만 맞아도** 일치추정량을 제공한다.

### 💻 실습: SDID 추정하기

```python
# SDID 핵심 로직: 이중 가중치 동시 최적화
# 목적 함수: 가중 DID + 정규화

sdid_loss = (Σλₜ·Y_treated - Σλₜ·(Y_control^T @ ω))**2
objective = lambda params: sdid_loss + α·(Σω² + Σλ²)

# 제약: Σωⱼ=1, Σλₜ=1, ω≥0, λ≥0
constraints = [
    {'type': 'eq', 'fun': lambda p: np.sum(p[:n_units]) - 1},
    {'type': 'eq', 'fun': lambda p: np.sum(p[n_units:]) - 1}
]
result = minimize(objective, params_init, constraints=constraints)

# 처치효과: 가중 DID
ω_opt, λ_opt = result.x[:n_units], result.x[n_units:]
```

## 4.5 검증 방법론 🔍

### "결과를 의심하고 확인하기" - 세 가지 검증 기법

좋은 연구는 결과를 자기 스스로 검증한다. SCM과 SDID에서는 세 가지 검증 방법이 핵심이다.

### 1️⃣ 플라시보 검정 - "다른 도시에서도 효과가 나타나는가?"

플라시보 검정은 **"진짜 효과인지, 우연인지"**를 구별하는 방법이다. 모든 대조 도시에 대해 "이 도시가 처치를 받았다"고 가정하고 가상의 효과를 계산한다. 만약 진짜 처치 도시의 효과가 가상 효과들 중에서 **가장 극단적**이라면, 그것은 우연이 아닐 가능성이 높다.

**💊 비유**: 진짜 약을 먹은 사람 1명과 위약(플라시보)을 먹은 20명을 비교한다. 진짜 약을 먹은 사람의 효과가 21명 중 가장 크다면, 약이 진짜 효과가 있을 가능성이 높다. p-value = 1/21 ≈ 0.048

### 2️⃣ Leave-one-out 분석 - "특정 도시에 의존하지 않는가?"

대조 도시를 하나씩 빼보면서, 결과가 크게 변하는지 확인한다. 한 도시를 뺐을 때 결과가 30% 이상 변하면 그 도시에 과도하게 의존하는 것이고, 모든 도시를 빼도 ±10% 이내면 매우 안정적이다.

### 3️⃣ 시간 플라시보 - "정책 전에도 효과가 있었는가?"

실제 정책 시점보다 앞선 시점에서 "정책이 시행되었다"고 가정하고 가상 효과를 계산한다. 만약 정책 전에도 유의한 효과가 나타나면, 평행추세 가정이 위배되었거나 다른 문제가 있다는 경고 신호다.

### 💻 실습: 플라시보 검정 구현하기

```python
# 플라시보 검정 (순열 기반 추론)
placebo_effects = []
for donor_idx in range(n_donors):
    # 각 donor를 가상 처치군으로 설정
    Y_placebo_pre = Y_donors_pre[:, donor_idx]
    Y_placebo_post = Y_donors_post[:, donor_idx]

    Y_other_pre = np.delete(Y_donors_pre, donor_idx, axis=1)
    Y_other_post = np.delete(Y_donors_post, donor_idx, axis=1)

    # SCM 가중치 계산 (최적화)
    w_init = np.ones(n_donors-1) / (n_donors-1)

    objective = lambda w: np.sum((Y_placebo_pre - Y_other_pre @ w)**2)
    constraints = {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
    result = minimize(objective, w_init, constraints=constraints, bounds=[(0,1)]*(n_donors-1))

    # 가상 처치효과 계산 (사후 평균)
    placebo_effects.append(np.mean(Y_placebo_post - Y_other_post @ result.x))

# p-value: rank/(J+1) 순위 기반
p_value = np.sum(np.abs(placebo_effects) >= np.abs(real_effect)) / (len(placebo_effects) + 1)
```

## 4.6 종합 구현 🔧

### 분석 워크플로우 5단계

실무에서는 DID, SCM, SDID를 모두 적용하고 결과를 비교하는 **삼각검증(triangulation)** 접근이 권장된다.

**1단계: 데이터 준비** → 패널 데이터 구조 확인, 결측치 처리, 공변량 표준화
**2단계: 탐색적 분석** → 사전 추세 시각화, 공변량 균형 확인
**3단계: 방법론별 추정** → DID + DML + SCM + SDID
**4단계: 검증** → 사전 추세 검정, 플라시보, Leave-one-out, 민감도 분석
**5단계: 시각화 및 보고** → 이벤트 연구 그래프, 합성 대조군 비교 플롯

### 💻 실습: 전체 파이프라인

```python
# 종합 분석 파이프라인 (DID, SCM, SDID 비교)

# 1. DID 추정
did_model = PanelOLS(df['outcome'], df[['treat_post']],
                     entity_effects=True, time_effects=True).fit(cov_type='clustered')

# 2. SCM 추정
synth = Synth(df_treated['outcome'], df_donors,
              pre_period=(0, 20), post_period=(21, 30)).fit()

# 3. SDID 추정
sdid_result = synthdid_estimate(Y_matrix, N_treated=1, T_pre=20)

# 4. 결과 비교 및 강건성 검증
results = compare_methods(did_model, synth, sdid_result)
```

## 4.7 방법론 선택 전략과 연구 전망 🗺️

### 어떤 상황에서 어떤 방법을 쓸까?

<표 4-20: 방법론 선택 가이드>

| 상황                                 | 추천 방법              | 이유                        | 주의사항               |
| ------------------------------------ | ---------------------- | --------------------------- | ---------------------- |
| 처치 단위 다수 (N>20), 평행추세 타당 | DID                    | 간결성, 해석 용이           | 이질적 효과 검토       |
| 단일 처치, 풍부한 donor pool (J>30)  | SCM                    | 투명성, 사전 적합           | 가중치 집중도 확인     |
| 단일 처치, 평행추세 불확실           | SDID                   | 이중 강건성                 | 계산 복잡도 고려       |
| 비선형 관계, 고차원 공변량           | DML                    | 유연성                      | 해석 가능성 저하       |
| 엇갈린 처치 시점                     | Callaway-Sant'Anna     | 편향 방지                   | 구현 복잡도            |
| **고차원 + 엇갈린 처치**             | **DML + Callaway DID** | **이질성과 시점 모두 대응** | **계산 비용 높음**     |
| **고차원 + 단일 처치**               | **DML + SDID**         | **비선형성과 강건성 결합**  | **Nuisance 품질 중요** |

**실무 팁**: 가능하면 세 방법(DID, SCM, SDID)을 모두 적용하고 결과의 일관성을 확인하는 것이 가장 좋다. 세 방법이 비슷한 결과를 보이면 강건한 결론이고, 크게 다르면 각 가정을 재검토해야 한다.

### 향후 연구 방향

**딥러닝과의 결합**: Transformer 기반 Synthetic Control, RNN으로 시계열 의존성 포착 등 딥러닝이 인과추론과 결합되는 연구가 활발하다.

**다중 처치와 연속적 처치**: 현실의 정책은 여러 지역에 다른 강도로 적용되는 경우가 많다. Generalized SCM과 Matrix Completion Methods가 이런 복잡한 상황을 다룬다.

**설명가능성 향상**: SHAP, LIME 같은 도구로 머신러닝 기반 인과추론의 "블랙박스" 문제를 해결하려는 연구가 진행 중이다.

## 📝 핵심 정리

| 방법 | 핵심 아이디어 | 장점 | 한계 |
| ---- | ------------- | ---- | ---- |
| DID | 전후 × 그룹 간 이중 비교 | 간단, 해석 쉬움 | 평행추세 가정 필요 |
| DML-DID | ML로 방해요소 제거 후 DID | 비선형 통제 가능 | 계산 복잡, 해석 어려움 |
| DR-DID | 결과 회귀 + 성향점수 "이중 보험" | 하나만 맞아도 OK | 두 모형 모두 틀리면 실패 |
| SCM | 여러 도시를 섞어 "가짜 처치군" 생성 | 투명, 단일 처치에 적합 | 사전 적합 필요, donor pool 의존 |
| SDID | DID + SCM 결합 | 이중 강건성, 높은 효율성 | 계산 복잡 |
