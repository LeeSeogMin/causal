## 1.1 예측과 인과

### 1.1.1 두 질문은 다르다

쇼핑몰 데이터로 답할 수 있는 질문을 두 가지 적어 보자.

- **질문 A**: 이 고객이 다음 달에 얼마를 살 것인가
- **질문 B**: 이 고객에게 쿠폰을 보내면 구매액이 얼마나 늘어나는가

둘은 다른 질문이다. A는 지금 있는 데이터를 그대로 두고 답한다. B는 **값을 바꿔 넣었을 때**를 묻는다. 쿠폰을 안 받은 고객에게 쿠폰을 줬다면 얼마를 샀을지는 데이터 어디에도 적혀 있지 않다.

![그림 1-1. 예측과 인과는 다른 질문에 답한다](../diagrams/1-1.png)

A에 답하는 것이 **예측**이고, B에 답하는 것이 **인과추론**이다.

### 1.1.2 왜 A를 잘해도 B를 못 하는가

실습 2(1-2)에서 이 차이를 직접 확인한다. 결과를 먼저 보면 이렇다.

| 항목 | 값 |
|------|-----|
| 예측 모형의 결정계수(R²) | 0.552 |
| 쿠폰 받은 고객과 안 받은 고객의 구매액 차이 | 12,710원 |
| 쿠폰의 참 효과 | 3,000원 |

구매액은 상당히 잘 맞힌다. 그런데 쿠폰 효과는 참값의 4.2배로 나왔다. **모형이 부실해서가 아니다.** 두 질문이 다르기 때문이다.

이유는 데이터를 만든 방식에 있다. 쿠폰은 무작위로 뿌려지지 않았다. 앱을 자주 여는 고객이 쿠폰을 더 많이 받아 갔고, 그 고객들은 원래부터 많이 사던 사람들이다.

```
쿠폰 받은 고객의 구매액이 높은 이유
  = 쿠폰 효과 (3,000원)
  + 원래 많이 사던 사람이라서 (9,710원)
```

단순 비교는 이 둘을 갈라내지 못한다.

**비유: 체온계와 해열제**

| 체온계와 해열제 | 예측과 인과 |
|-----------------|-------------|
| 체온계로 38.5도를 잰다 | 예측 모형으로 구매액을 맞힌다 |
| 체온계는 열이 몇 도인지 알려준다 | 예측 모형은 얼마를 살지 알려준다 |
| 해열제를 먹으면 몇 도 내려가는가 | 쿠폰을 보내면 얼마가 늘어나는가 |
| 체온계로는 이 질문에 답할 수 없다 | 예측 모형으로는 이 질문에 답할 수 없다 |
| 약을 먹은 사람과 안 먹은 사람을 비교하면? | 쿠폰 받은 사람과 안 받은 사람을 비교하면? |
| 약을 먹은 사람이 원래 더 아팠다 | 쿠폰 받은 고객이 원래 더 많이 샀다 |

비유가 맞아떨어지는 지점은 마지막 두 줄이다. **아픈 사람이 약을 먹는다.** 그래서 약 먹은 집단의 체온이 더 높게 나온다. 이 숫자를 그대로 "약이 열을 올린다"고 읽으면 안 된다.

### 1.1.3 변수 중요도는 인과효과가 아니다

실습 2에서 예측 모형의 변수 중요도를 뽑으면 이렇게 나온다.

| 변수 | 중요도 |
|------|--------|
| 앱 접속 | 0.642 |
| 나이 | 0.220 |
| 가입기간 | 0.113 |
| 쿠폰 수령 | 0.025 |

쿠폰이 **가장 낮다.** 앞에서는 단순 비교로 12,710원이 나왔는데, 여기서는 거의 쓸모없는 변수로 나온다. 두 숫자가 서로 반대 방향으로 틀렸다.

- 단순 비교(12,710원)는 충성도 차이를 쿠폰 몫으로 잘못 넘겼다.
- 변수 중요도(0.025)는 앱 접속이 충성도 정보를 이미 담고 있어서, 쿠폰이 추가로 설명할 게 없다고 판단했다.

**변수 중요도는 "예측에 얼마나 도움이 되는가"를 재는 값이지 "바꾸면 결과가 얼마나 달라지는가"를 재는 값이 아니다.** 실무에서 가장 자주 나오는 착각이다.

### 1.1.4 인과 데이터 사이언스가 서 있는 세 가지 기반

인과 데이터 사이언스(Causal Data Science)는 "무엇을 해야 원하는 결과를 얻는가"에 답하는 분야다(Hernán & Robins, 2020). 실무에서 작동하려면 세 가지가 갖춰져야 한다.

- **데이터**: 행정 데이터, 거래 기록, 센서, 텍스트 등 대규모 자료를 모아 쓴다. 표본 수백 개로는 집단별로 효과가 어떻게 다른지 볼 수 없다.
- **모형**: 머신러닝으로 복잡한 관계를 학습하고, 개입 결과를 사전에 계산한다.
- **평가**: 효과를 실행과 동시에 측정하고, 그 결과를 다음 결정에 반영한다.

세 가지 중 하나만 빠져도 작동하지 않는다. 데이터가 많아도 인과 설계가 없으면 실습 2의 12,710원 같은 값이 나오고, 설계가 좋아도 데이터가 없으면 추정이 흔들린다.

### 1.1.5 에스토니아: 데이터 기반이 갖춰진 경우

에스토니아는 인구 130만의 작은 나라인데 정부 서비스의 99%를 온라인으로 제공한다(e-Estonia, 2024a).

- **X-Road**: 정부 기관 간 데이터 교환 플랫폼. 연간 22억 건 이상이 오가며, 약 1,345년 분의 근무 시간을 절감한다(e-Estonia, 2024b)
- **Bürokratt**: 시민 문의를 자동 처리하는 AI 시스템
- **디지털 ID**: 보급률 99%. 모든 정부 서비스에 하나의 신원으로 접근한다

여기서 볼 점은 기술 자체가 아니라 **데이터가 한곳에 모여 있다는 사실**이다. 부처마다 자료가 흩어져 있으면 "이 정책을 받은 사람이 그 뒤에 어떻게 됐는가"를 추적할 수 없다. 추적이 안 되면 인과추론도 안 된다.

### 1.1.6 한국의 현황

한국은 2024년 UN 전자정부 평가에서 193개국 중 4위다(United Nations, 2024). 온라인 서비스와 통신 인프라가 세계 최고 수준이다.

- **정부24**: 중앙부처와 지자체 서비스를 통합한 창구
- **공공데이터포털**: 10만 개 이상의 데이터를 개방했다(행정안전부, 2024)
- **코로나19 대응**: 마스크 재고 실시간 공개가 국제적 모범 사례로 인정받았다

기말 프로젝트에서 실제 데이터를 쓰고 싶다면 공공데이터포털(data.go.kr)과 KOSIS(kosis.kr)에서 시작하면 된다.

## 1.2 인과적 데이터 사이언스 프레임워크

### 1.2.1 전통적 분석·평가 모델의 세 가지 한계

전통적 방식은 "문제 정의 → 대안 설계 → 의사결정 → 실행 → 평가"를 순서대로 한 번 지나간다. 반세기 넘게 쓰인 틀이지만 세 가지에서 막힌다.

| 한계 | 무엇이 문제인가 | 구체적으로 |
|------|-----------------|-----------|
| 시간 지연 | 평가가 실행 한참 뒤에 나온다 | 3년 사업의 평가가 4년째에 나오면 고칠 기회가 없다 |
| 정보 비대칭 | 현장 상황이 위로 올라가지 않는다 | 담당 공무원은 아는 문제를 결정권자는 모른다 |
| 단절적 피드백 | 피드백이 평가 단계에서만 생긴다 | 실행 중 발견한 문제를 그 자리에서 못 고친다 |

### 1.2.2 5단계 순환 구조

이 한계를 넘기 위해 각 단계를 순환으로 잇는다.

![그림 1-2. 인과적 데이터 사이언스의 5단계 순환](../diagrams/1-2.png)

**1단계: 문제 정의** — 데이터에서 문제를 찾는다. 정기 보고서를 기다리지 않고, 고객센터 문의·앱 삭제율·반품률 같은 신호를 실시간으로 본다.

**2단계: 대안 설계** — 과거 유사 사례의 성과 데이터를 학습해 후보를 만든다. 시뮬레이션으로 부작용을 미리 본다.

**3단계: 의사결정** — 여러 기준으로 대안을 평가한다. 이해관계자마다 중요하게 보는 것이 다르므로 가중치를 나눠 반영한다.

**4단계: 적응형 실행** — 반응을 보며 배분을 조정한다. A/B 테스트처럼 끝날 때까지 기다리는 대신, 성과가 좋은 쪽에 노출을 늘려 간다. 8장에서 다룬다.

**5단계: 평가와 학습** — 효과를 측정한다. 여기가 이 교재의 중심이다. 2장부터 7장까지가 전부 이 단계의 방법이다.

### 1.2.3 5단계에서 하는 일

5단계가 전통적 평가와 다른 점은 세 가지다.

- **실시간 평가**: 사업이 끝난 뒤가 아니라 진행 중에 측정한다.
- **인과적 평가**: 다른 요인의 몫을 걷어내고 개입 자체의 효과만 재려 한다. 실습 2에서 본 12,710원과 3,000원의 차이를 갈라내는 일이다.
- **적응적 학습**: 평가 결과가 다음 순환의 문제 정의로 돌아간다.

### 1.2.4 피드백 루프 세 종류

**비유: 자동차 내비게이션**

| 내비게이션 | 5단계 순환 |
|------------|-----------|
| 출발 전 경로를 정한다 | 1~3단계: 문제 정의부터 의사결정까지 |
| 주행 중 정체 정보를 받아 경로를 바꾼다 | 4단계: 적응형 실행 |
| 도착 후 실제 소요 시간이 기록된다 | 5단계: 평가 |
| 그 기록이 다음 경로 추천에 반영된다 | 평가 결과가 다음 순환으로 |
| 목적지에 도착해야만 경로를 바꿀 수 있다면 | 전통적 선형 모델 |

내비게이션이 목적지 도착 후에만 경로를 바꿀 수 있다면 쓸모가 없다. 전통적 평가 모델이 그런 구조였다.

피드백은 세 가지 크기로 돌아간다.

- **짧은 주기**: 한 단계 안에서 즉시 조정한다. 실행 중 이상 신호를 발견하면 그 자리에서 고친다.
- **긴 주기**: 5단계를 전부 돈 뒤 전략 자체를 바꾼다.
- **건너뛰기**: 실행 단계 데이터가 평가를 거치지 않고 설계 단계로 바로 간다.

## 1.3 어떤 방법을 쓸 것인가

### 1.3.1 무작위 배정이 기준점이다

실습 3(1-3)에서 같은 모집단, 같은 계산인데 답이 갈리는 것을 확인한다.

| 데이터 | 쿠폰을 누가 받았나 | 두 집단 충성도 차이 | 추정 효과 |
|--------|--------------------|---------------------|-----------|
| 관찰 | 고객이 스스로 선택 | +0.76 | 12,373원 |
| 실험 | 동전을 던져 배정 | -0.00 | 2,978원 |

참 효과는 3,000원이다. 실험 데이터는 맞히고 관찰 데이터는 4.1배로 틀린다.

**차이를 만든 것은 계산 방법이 아니라 누가 쿠폰을 받았는가다.**

**비유: 제비뽑기로 조 나누기**

| 조 나누기 | 처치 배정 |
|-----------|-----------|
| 하고 싶은 사람이 손 들어 A조에 간다 | 고객이 스스로 쿠폰을 받아 간다 |
| A조에 의욕적인 학생이 몰린다 | 쿠폰 집단에 충성도 높은 고객이 몰린다 |
| A조 성적이 좋아도 조 편성 덕인지 알 수 없다 | 구매액이 높아도 쿠폰 덕인지 알 수 없다 |
| 제비뽑기로 나눈다 | 무작위로 배정한다 |
| 두 조의 평균 실력이 같아진다 | 두 집단의 충성도 평균이 같아진다(-0.00) |
| 그다음 성적 차이는 조 편성 효과다 | 그다음 구매액 차이는 쿠폰 효과다(2,978원) |

무작위 배정은 처치 말고 다른 모든 것을 두 집단에서 평균적으로 같게 만든다. 그래서 남는 차이를 처치 효과로 읽을 수 있다.

### 1.3.2 무작위 배정을 못 하는 경우

문제는 무작위 배정이 자주 불가능하다는 것이다.

- **윤리**: 어떤 학생에게만 장학금을 주고 나머지를 대조군으로 둘 수 없다.
- **법·제도**: 소득 기준을 충족한 모든 가구에 지급해야 하는 급여를 무작위로 줄 수 없다.
- **비용·시간**: 도시 절반에 지하철을 놓고 절반에 안 놓는 실험은 불가능하다.
- **이미 벌어진 일**: 작년에 시행된 정책의 효과를 지금 실험으로 확인할 수 없다.

이럴 때 관찰 데이터에서 인과효과를 찾아내는 방법이 2장부터 7장까지의 내용이다.

### 1.3.3 방법을 고르는 기준

전통적 방법론과 AI 기반 방법론 중 무엇을 쓸지는 상황이 정한다.

| 상황 | 적합한 쪽 | 이유 |
|------|-----------|------|

## 실습 2 (1-2). 예측과 인과는 다른 질문에 답한다

### 목적

잘 맞히는 예측 모형이 "쿠폰을 보내야 하는가"에 답하지 못한다는 것을 숫자로 확인한다.

### 상황 설정

| 역할 | 변수 | 설명 |
|------|------|------|
| 결과 Y | 구매액 | 월 구매 금액(원) |
| 처치 D | 쿠폰 수령 여부 | 0 또는 1 |
| 관측 변수 X | 나이, 가입기간, 월 앱 접속 횟수 | 분석에 쓸 수 있다 |
| 숨은 원인 U | 충성도 | 쿠폰 수령과 구매액 둘 다에 영향(관측 불가) |

쿠폰의 참 효과는 **3,000원**으로 정해 두었다.

### 실행

```bash
python 1-2-prediction-vs-causation.py
```

### 실제 출력

```
[1단계] 데이터 만들기
고객 수: 5,000명
쿠폰 수령률: 39.4%
쿠폰의 참 효과: 3,000원  (데이터를 만들 때 넣은 값)

[2단계] 쿠폰 받은 고객과 안 받은 고객을 그냥 비교하면
쿠폰 받은 고객 평균 구매액:       53,717원  (n=1,971)
쿠폰 안 받은 고객 평균 구매액:     41,007원  (n=3,029)
차이:                            12,710원

참 효과 3,000원의 4.2배로 부풀려졌다.

[3단계] 예측 모형을 학습시키면
테스트셋 결정계수(R²): 0.552
구매액을 상당히 잘 맞힌다.

변수 중요도:
  앱 접속     0.642
  나이       0.220
  가입기간     0.113
  쿠폰 수령    0.025

[4단계] 왜 어긋났는가
두 집단은 쿠폰 말고도 다른 점이 있다.
  충성도 평균     쿠폰 받음   0.46  vs  안 받음  -0.29
  월 앱 접속 횟수  쿠폰 받음   10.8  vs  안 받음    6.7
```

### 출력 해석

**`차이: 12,710원`**

가장 먼저 계산하게 되는 값이고, 가장 자주 틀리는 값이다. 참값 3,000원의 4.2배다.

이 숫자를 그대로 믿으면 "쿠폰 한 장이 12,710원을 만든다"는 결론이 나온다. 실습 3에서 이 결론이 얼마짜리 오판인지 계산한다.

**`테스트셋 결정계수(R²): 0.552`**

결정계수는 결과변수의 변동 중 모형이 설명한 비율이다. 0.552는 55.2%를 설명했다는 뜻이다. 예측 모형으로는 쓸 만하다.

**여기가 이 실습의 핵심이다.** 예측 성능이 좋다는 사실은 인과 추정이 옳다는 근거가 되지 못한다. 두 지표는 서로 다른 것을 재기 때문이다.

| 지표 | 재는 것 | 답하는 질문 |
|------|---------|-------------|
| 결정계수 0.552 | 예측이 실제와 얼마나 가까운가 | 이 고객이 얼마를 살 것인가 |
| 참값과의 차이 | 추정 효과가 참 효과와 얼마나 가까운가 | 쿠폰을 보내면 얼마가 늘어나는가 |

**`쿠폰 수령 0.025`**

변수 중요도에서 쿠폰이 가장 낮다. 앞의 12,710원과 정반대 방향이다.

앱 접속 횟수가 충성도 정보를 이미 담고 있어서, 쿠폰을 추가로 알려 줘도 예측이 별로 나아지지 않기 때문이다. 중요도는 **예측에 얼마나 보태는가**를 재는 값이지 인과효과가 아니다.

정리하면 같은 데이터에서 두 개의 틀린 답이 반대 방향으로 나왔다.

| 방법 | 나온 값 | 방향 |
|------|---------|------|
| 단순 비교 | 12,710원 | 참값의 4.2배로 과대 |
| 변수 중요도 | 0.025 (최하위) | 효과가 거의 없다고 과소 |
| 참값 | 3,000원 | |

**`충성도 평균: 쿠폰 받음 0.46 vs 안 받음 -0.29`**

원인이 여기 있다. 두 집단은 쿠폰 말고도 다른 점이 있다. 충성도가 0.75만큼 차이 난다. 앱 접속 횟수도 10.8회와 6.7회로 갈린다.

쿠폰을 받은 고객은 원래부터 이 쇼핑몰을 자주 쓰던 사람이다. 12,710원 안에 그 차이가 섞여 들어갔다.

### 그래프 읽기

![예측과 인과](../practice/chapter01/code/1-2-prediction-vs-causation.png)

- **(a)** 두 막대 높이 차이가 12,710원이다. 이 그림만 보면 쿠폰 효과가 커 보인다.
- **(b)** 충성도 분포 두 개가 겹치기는 하지만 중심이 어긋나 있다. 파란 쪽(쿠폰 받음)이 오른쪽에 있다. **비교하려는 두 집단이 애초에 다르다는 증거다.**
- **(c)** 단순 비교(12,710원)와 참값(3,000원)을 나란히 놓았다. 막대 높이 차이가 오차의 크기다.

(b)를 (a)보다 먼저 봤어야 한다. 두 집단이 비교 가능한지 확인하지 않고 평균 차이부터 계산한 것이 문제였다.

### 확인 문제

1. 결정계수 0.552는 무엇을 재는 값인가. 이 값이 0.9였다면 쿠폰 효과 추정이 더 정확해지는가.
2. 변수 중요도에서 쿠폰이 최하위인데 단순 비교는 12,710원이다. 두 결과가 왜 어긋나는가.
3. 충성도를 관측할 수 있었다면 무엇을 할 수 있었겠는가.

## 실습 3 (1-3). 무작위 배정이 답을 바꾼다

### 목적

같은 모집단에 같은 계산을 적용해도 **데이터를 어떻게 모았느냐**에 따라 답이 달라지는 것을 확인하고, 그 차이가 얼마짜리인지 돈으로 계산한다.

### 실행

```bash
python 1-3-randomization.py
```

### 실제 출력

```
[1단계] 관찰 데이터: 고객이 스스로 쿠폰을 받아 갔다
쿠폰 수령률: 39.5%
두 집단 충성도 차이: +0.76  (0에서 멀수록 집단이 다르다)
평균 구매액 차이: 12,373원

[2단계] 실험 데이터: 동전을 던져 무작위로 배정했다
쿠폰 수령률: 50.0%
두 집단 충성도 차이: -0.00  (무작위 배정이라 0에 가깝다)
평균 구매액 차이: 2,978원
95% 신뢰구간: [2,177원, 3,779원]
신뢰구간이 참값 3,000원을 포함하는가: 예

[3단계] 같은 계산, 다른 답
데이터   쿠폰배정  충성도차이  추정효과 참값대비
 관찰 고객이 선택   0.76 12373 4.1배
 실험 동전 던지기  -0.00  2978 1.0배

[4단계] 이 차이는 얼마짜리인가
쿠폰 1장 비용: 5,000원
전체 고객: 1,000,000명

관찰 데이터를 믿으면
  쿠폰 1장당 순이익: 12,373 - 5,000 = 7,373원 → 발행한다
  전 고객 발행 시:   73.7억원
실제로는
  쿠폰 1장당 순이익: 3,000 - 5,000 = -2,000원 → 발행하지 않는다
  전 고객 발행 시:   -20.0억원

관찰 데이터를 믿고 100만 장을 발행하면 실제로는 20.0억원 손실이다.
```

### 출력 해석

**`두 집단 충성도 차이: +0.76` vs `-0.00`**

이 두 숫자가 모든 것을 설명한다.

관찰 데이터에서는 쿠폰 집단의 충성도가 0.76 더 높다. 실험 데이터에서는 차이가 사실상 0이다. 동전을 던져 배정했으므로 충성도가 높은 고객과 낮은 고객이 양쪽에 골고루 들어갔다.

**무작위 배정이 하는 일이 정확히 이것이다.** 처치 말고 다른 모든 것을 두 집단에서 평균적으로 같게 만든다. 충성도뿐 아니라 관측하지 못하는 변수까지 같아진다는 점이 중요하다.

**`평균 구매액 차이: 12,373원` vs `2,978원`**

두 데이터에 **똑같은 계산**을 했다. 처치 집단 평균에서 통제 집단 평균을 뺐을 뿐이다. 그런데 답이 4.1배 차이 난다.

**차이를 만든 것은 분석 방법이 아니라 데이터를 모은 방식이다.** 이 문장이 이 과목 전체의 출발점이다. 아무리 정교한 모형을 써도, 처치가 어떻게 배정됐는지를 다루지 않으면 답이 어긋난다.

**`95% 신뢰구간: [2,177원, 3,779원]`**

실험 추정치 2,978원에 붙는 구간이다. 폭이 1,602원으로 넓다. 표본이 5,000명이고 구매액의 변동이 크기 때문이다.

참값 3,000원이 이 구간 안에 들어 있다. 추정치가 참값과 정확히 같지 않아도(2,978 vs 3,000) **구간이 참값을 포함하면 정상이다.**

**`관찰 데이터를 믿고 100만 장을 발행하면 20.0억원 손실`**

계산은 단순하다.

```
쿠폰 1장당 순이익 = (쿠폰 효과) - (쿠폰 비용 5,000원)

관찰 데이터를 믿을 때: 12,373 - 5,000 = +7,373원  → 발행한다
실제로는:              3,000 - 5,000 = -2,000원  → 발행하면 안 된다
```

부호가 뒤집힌다. **크기가 틀린 정도가 아니라 결정 자체가 반대로 간다.** 100만 명에게 발행하면 73.7억원을 기대하고 시작해서 20.0억원을 잃는다.

인과추론을 배우는 이유가 여기 있다. 틀린 추정치는 틀린 결정을 낳고, 결정에는 값이 붙는다.

### 그래프 읽기

![무작위 배정](../practice/chapter01/code/1-3-randomization.png)

- **(a)** 두 집단의 충성도 차이다. 관찰 데이터(주황)는 0.76으로 높이 솟아 있고, 실험 데이터(파랑)는 0에 붙어 있다. **막대가 낮을수록 비교 가능한 두 집단이다.**
- **(b)** 관찰·실험·참값을 나란히 놓았다. 실험 막대와 참값 막대의 높이가 거의 같고, 관찰 막대만 4배 높다.
- **(c)** 100만 장 발행의 손익이다. 왼쪽은 관찰 데이터를 믿었을 때 기대한 +73.7억원, 오른쪽은 실제 결과인 -20.0억원이다. **막대가 0선 위아래로 갈린다.**

(a)를 먼저 확인하는 습관이 중요하다. 두 집단이 처치 말고 다른 점이 있는지 보지 않고 (b)의 평균 차이부터 계산하면 실무에서 사고가 난다.

### 확인 문제

1. 실험 데이터의 충성도 차이가 -0.00이다. 무작위 배정이 관측하지 못하는 변수까지 같게 만드는 이유를 설명하라.
2. 실험 추정치가 2,978원으로 참값 3,000원과 22원 다르다. 이 차이는 편향인가 우연인가. 근거는 무엇인가.
3. 쿠폰 비용이 5,000원이 아니라 2,000원이었다면 관찰 데이터를 믿었을 때와 실제 결과의 결정이 갈리는가.
4. 이 쇼핑몰이 무작위 실험을 할 수 없는 상황을 두 가지 들어라.

## 1장 핵심 정리

```
1. 데이터로 답하는 질문은 두 가지다
   → 예측: 이 고객이 얼마를 살 것인가
   → 인과: 쿠폰을 보내면 얼마가 늘어나는가
   → 이 교재는 두 번째 질문을 다룬다

2. 예측을 잘해도 인과는 못 맞힌다
   → 실습 1-2: 결정계수 0.552인데 쿠폰 효과는 참값의 4.2배로 나왔다

3. 변수 중요도는 인과효과가 아니다
   → 실습 1-2: 쿠폰의 중요도가 0.025로 최하위인데 단순 비교는 12,710원
   → 같은 데이터에서 두 틀린 답이 반대 방향으로 나왔다

4. 틀리는 원인은 두 집단이 처치 말고도 다르다는 데 있다
   → 실습 1-2: 충성도 평균 0.46 vs -0.29

5. 무작위 배정은 처치 말고 다른 모든 것을 평균적으로 같게 만든다
   → 실습 1-3: 충성도 차이가 관찰 +0.76에서 실험 -0.00으로

6. 같은 계산, 다른 답
   → 실습 1-3: 관찰 12,373원 / 실험 2,978원 / 참값 3,000원
   → 차이를 만든 것은 분석 방법이 아니라 데이터를 모은 방식이다

7. 틀린 추정치에는 값이 붙는다
   → 실습 1-3: 순이익 부호가 +7,373원에서 -2,000원으로 뒤집힌다
   → 100만 장 발행 시 73.7억원을 기대하고 20.0억원을 잃는다

8. 무작위 배정은 윤리·법·비용·시점 때문에 자주 불가능하다
   → 그때 관찰 데이터로 인과효과를 찾는 방법이 2~7장이다

9. 방법에 우열은 없다. 쓸 수 있는 조건이 다를 뿐이다
```
